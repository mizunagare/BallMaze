# 猫族图标与物品规范 v1

CatWorldProps定义真实3D道具，CatWorldBake在独立摄影场景生成42张透明256×256PNG；保持统一相机、方向、柔和阴影与边距。原有AdventureIcons作为缺图回退，来源许可继续保留。图标摄影shader不用于改变战斗照明。

实际材料：野怪皮、晶石碎片、领主核心、木材、石头、铁矿。模板草药、食用蘑菇、布料、卷轴、任务物品仅CONCEPT_ONLY，不能假装存在配方或库存。蘑菇猫怪并不代表新增食材。

白/绿/紫/金/红品质使用既有属性和占格规则，UI框与文字共同提示；新图标不创建独立经济系统。药水继续原制作/消耗/Q快捷栏，四武器原类型不改。掉落外观只替换Renderer子物体，不自动拾取、不改唯一ID和来源账。

24/32/48/64/128检查记录必须引用实际缩放图。没有执行的尺寸或人工图标辨识明确NOT_RUN；不得将美术权重称为已完成平衡。
