# 猫族环境规范 v1

森林绿/木棕/米白/天空蓝构成主色；金色只用于重要标记。木材哑光、金属较低粗糙度、帆布柔和、石头中灰，保持材质差异而非堆叠高光与粒子。

营地保留既有地面和四设施业务，增加功能猫、旗帜和物资标记。森林树冠以厚实体块组合，岩体使用圆角体积，遗迹与出口使用猫族符号。CatWorldScenery仅添加或替换Renderer；禁止新增阻路碰撞、改变地形版本或对旧在途插入障碍。

湖面和水面显灵分别处理，深水阻挡及岸边可攻击本体不变。免费出口与渡口仍使用原导航、互动距离及2木1石交易。当前不是整张森林重建，也不是自由行走营地新系统。

后续接口（仅概念）：火山红黑与熔岩、冰原蓝白与磨砂冰、海底青绿与珊瑚、天空米金与云、龙域紫金；本批不生成这些地图或玩法。
