## 1. 为什么要提这个

**[源]** 四把旧武器从紫起就有品质专属：

| 武器 | 紫 | 金 | 红 | 出处 |
|---|---|---|---|---|
| 长剑 | +1 道剑气 0.75× | 3 道剑气（±18°）共 2.25× | 剑气带 1.8m 爆裂 | `AdventureCombat.cs:186` |
| 长枪 | 追加 9m 穿刺余波 0.80× | 余波更宽 | 追加远程枪芒 1.00× | `:187` |
| 法杖 | 爆半径 4→5m | 2 枚侧球各 0.80× | 侧球半径 1.6→3m | `:109,188` |
| 弓 | 5→7 箭 | 各箭 1.5m 爆炸 | 7→9 箭 | `:108,189` |

**[源]** 三把新武器被 `WeaponTraits.Exclusive` 统一返回「独立武器机制 · 通用词缀按实际命中结算；技能见当前武器说明」（`WeaponTraits.cs:10`），**没有任何品质专属**；`WeaponSkillDefinition` 没有 quality 字段，`WeaponSkillExpansion.Release` 也不读 `source.quality`。
**[推]** 结合 `CALC_MODEL.md §5.3`：旧武器槽 0 的白→红倍率增长 1.73–2.13 倍，而 14 项扩展技能与三把新武器全部原地不动。装备越好，断层越宽。

## 2. 提案的硬边界

| 允许 | 禁止 |
|---|---|
| 复用**已存在的参数族**：段数、半径、距离、时长、倍率、追加一次同类型判定 | 新增武器 / 技能 / 词缀 / 货币 |
| 品质门槛沿用 `GearQuality.Purple / Gold / Red` | 强化 / 重铸 / 升星 / 单件升级（D-10） |
| 紫/金/红每档只改**一个**参数，便于逐档验收 | 改 Boss / ForestBoss 的控制免疫（`EnemyWeaponControl.cs:4`） |
| 品质专属绑定装备品质，与铭刻词缀解耦 | 改掉落率 / 配方 / 随机流 / v9-v10 |

## 4. 与回响 / 聚能的交互（必须一并核对）

| 提案 | 回响（现状） | 聚能（E-A 后） |
|---|---|---|
| 双刃金 8 段 | `TwinHit` 的 `phase>=10` 吃 1.25 胶囊放大 | +25% 伤害、+1s 冷却 |
| 巨剑金 波半径 | `NewGroundShock.Spawn` 的 `area=Has(id2)?1.25:1` 会**再乘 1.25** → 0.42→0.525m，limit 10→12.5m | `WeaponHit.Apply(...,true)` 吃 +25% |
| 镰刀金 牵引距离 | `PullSector` 的 `4.5f*(Has(id2)?1.25:1)` 同样会叠乘 → 5.6→7.0m | 0 伤害，不受聚能影响；冷却 +1s |

**[推] 结论**：**巨剑金与镰刀金两条提案与回响存在叠乘**，实现批必须先决定「品质专属参数是否参与回响放大」。本规格建议：**参与**（与旧武器 `StaffBlastRadius(q,area)` 同构），但必须把叠乘后的上界写进 Player 验收断言，否则会出现 7m 牵引 / 0.525m 波这类未经评估的数值。
