# 《万象归途》黑猫猫族世界：单条 Prompt 速用版

本文件提供“可以直接复制给出图模型”的简洁版本提示词，适合单张概念图、角色图、场景图和 UI 图使用。

---

## 1. 总体风格总控 Prompt

为游戏《万象归途》设计原创卡通奇幻冒险美术。世界观为“猫族冒险世界”，主角是一只黑猫冒险者，营地 NPC 也是不同职业与品种的猫，敌人与 Boss 为猫科主题的森林魔物。整体风格为立体卡通材质、清晰轮廓、高辨识度、温暖明快配色，适合第三人称斜俯视角动作冒险游戏，包含营地整备、森林探索、搜集、战斗、撤离与带回成长。UI 要简洁易读，场景、角色、道具和图标属于同一世界观。不要写实恐怖、不要现代军事风、不要抄袭现有游戏角色与界面。

---

## 2. 黑猫主角 Prompt

设计《万象归途》的主角：一只黑猫冒险者，卡通奇幻风格，适合第三人称斜俯视角动作冒险游戏。主角有明显猫耳、尾巴、黑色毛发、红围巾、小背包、轻甲和旅行者气质。因为毛色较深，请用浅色面部、围巾和装备高光增强可读性。输出正面、侧面、背面和待机姿态，风格可爱但有冒险感，轮廓清楚，适合做 Unity 角色模型和 UI 头像。

---

## 3. 营地猫 NPC Prompt

为《万象归途》设计一组猫族营地 NPC，分别负责仓库、工作台、教程引导、出征准备和物资管理。要求全部是不同职业风格的猫猫角色，通过体型、毛色、服装、工具和配件区分功能。整体风格温暖、卡通、清晰、统一，适合作为营地功能角色。

---

## 4. 森林怪物 Prompt

为《万象归途》的森林区域设计一组猫科主题敌人与怪物，包含普通近战敌、远程敌、蘑菇怪、树灵、精英敌和 Boss。整体风格卡通奇幻，适合第三人称斜俯视角动作冒险游戏。普通敌、精英和 Boss 必须在体型、颜色和轮廓上明显分层，不能都长得很像。风格统一、轮廓清晰、易于游戏中识别。

---

## 5. 陆地 Boss Prompt

设计《万象归途》的森林陆地 Boss：古林狞猫守卫。它是一只巨大的猫科守卫 Boss，融合木甲、骨角、树藤和古老遗迹元素，体型巨大，轮廓强烈，具有高辨识度。整体风格卡通奇幻，适合动作冒险游戏 Boss 设计。请表现站立、冲锋、震地和远程投射等攻击姿态。

---

## 6. 湖中 Boss Prompt

设计《万象归途》的湖中 Boss：湖心潮灵猫。它是一只与水元素结合的猫科神兽，优雅、神秘、危险，适合作为湖泊区域 Boss。整体风格卡通奇幻，具有水波、潮印、潮矢等元素技能视觉，体型与轮廓明显区别于普通敌人。

---

## 7. 营地场景 Prompt

为《万象归途》设计猫族冒险营地场景。包含篝火、帐篷、仓库、工作台、出征准备区、路牌、旗帜、箱子、木桶、物资堆、植被和远景。整体风格温暖、卡通奇幻、功能清晰，像真实游戏中的中心营地，而不是测试平台。

---

## 8. 森林地图 Prompt

为《万象归途》设计初始森林地图“翡翠林海”。这是一张开放探索的卡通奇幻森林地图，包含林间主路、支路、湖泊、岩脊、遗迹、资源点、宝箱点、Boss 区域和撤离点。整体要层次分明、色彩明亮、道路清晰、适合第三人称斜俯视角动作冒险游戏。

---

## 9. 主菜单 Prompt

为《万象归途》设计正式主菜单 UI。背景是猫族营地和远处森林景色，整体风格卡通奇幻、温暖、冒险感强。界面包含游戏标题、继续游戏、新游戏、读取存档、设置和退出。按钮需要清晰、易点击、中文可读，适合 Unity uGUI 落地。

---

## 10. 背包与 HUD Prompt

为《万象归途》设计游戏内 HUD 和背包界面。风格简洁清晰、卡通奇幻、适合斜俯视角动作冒险游戏。HUD 重点展示生命、武器、技能、药水、目标和交互提示；背包界面展示分类标签、格子物品、装备栏、详情栏和稀有度边框。尽量减少长文字，优先用图标和短标签。

## 11. 图标 Prompt

为《万象归途》设计一套统一的卡通奇幻图标，包含木材、石块、矿石、晶体、药水、武器、护甲、宝箱、营地、仓库、工作台、遗迹、Boss、撤离点和可修复渡口。要求统一视角、统一描边、统一阴影与边距，高清晰度、高辨识度，适合游戏 UI 使用。
