## 2. 五个重点的结论

### 2.1 14 项扩展技能的收益与代价

**[推] 核心恒等式**：`η = 1 + (B−1)×W/C`，其中 `B = D/(R×W)` 是窗口内爆发系数。

| 发现 | 数值 |
|---|---|
| 现状 `B < 1` 的技能 | **8 / 14**（`sword.circle` 0.550、`sc.pull` 0、`twin.counter` 0.666、`bow.pierce` 0.701、`staff.echo` 0.711、`gs.wave` 0.731、`spear.charge` 0.881、`bow.burst` 0.907） |
| 现状 `η` 区间 | `0.932 – 1.044`；4 个旧槽 0 是 `1.071 / 1.107 / 1.086 / 1.357`，**扩展技能无一项达到** |
| 主因 | **窗口 W 太长**，不是倍率：`sword.circle` W=1.50s、`bow.pierce` 1.52s、`gs.cleave/wave` 1.30s，而槽 0 只有 0.50s |
| 提案结果 | 12 项 T1/T2 全部入带：`B' 1.025–1.652`、`η' 1.003–1.067`；T3 两项不纳入 η |
| 关键约束 | **B<1 时降冷却只会更糟**。这直接否定了「统一调冷却」和「倍率对齐」两类做法 |

**不追平槽 0 倍率**：槽 0 `W/C≈0.071`、扩展 `0.05–0.19`，结构不同；且槽 0 吃品质、扩展技能不吃。

### 2.2 回响词缀对普攻和技能的适用规则

**[源]** 准确口径（P02 曾把它写成「半死词缀」，本批更正，见 `ERRATA_P02.md`）：

| 类别 | 数量 | 回响 |
|---|---|---|
| 旧武器槽 0 | 4 | **生效**（半径 / 散射 / 爆半径 ×1.25） |
| 新武器技能 | 6 | **生效**（扇形 / 胶囊 / 牵引 / 冲击波 ×1.25） |
| 7 套普攻 | 7 | 不生效（`BeginAttack` 写了 `a.area`，`Release` 普攻分支不读） |
| 8 个旧扩展技能 | 8 | 不生效（`ExpandedMelee` 直接传 `def.reach`） |

**[推] 规格**：推荐 **R-1** —— 把「不适用普攻、不适用 8 个旧扩展技能」写成**明确规则**，定位为「技能形状专用词缀」，只改 L3 规则定义 + L4 文案，**0 行判定代码**。
R-2（补齐 8 个扩展技能）与 R-3（普攻也吃 `area`）都会改 `Melee` 的入参，属 **L2 攻击判定，需单独授权**。

### 2.3 聚能词缀的伤害收益与冷却代价对称性

| 侧 | 现状 | E-A 后 |
|---|---|---|
| 收益：18 个技能伤害 ×1.25 | 对称（含留场脉冲、地面波、贯穿弹） | 不变 |
| 代价：+1s 冷却 | **10 个收 / 8 个旧扩展技能白拿** | **18 个全收** |

**[源]** 缺口的 2 处代码：`WeaponSkillExpansion.cs:39` 的 `PrepareExpanded(def.cooldown)` 绕过词缀；`AdventureCombat.cs:104` 的 `SkillDuration` 直接返回 `def.cooldown`（连带 `SkillRemaining` 显示也错）。
**E-A** 只改这 2 处 + L4 显示，不动 `WeaponHit.Apply`。叠加 §2 提案后 8 项 η 下降 `−0.0003 ~ −0.0041`，**8/8 仍在目标带**（`FOCUS_SYMMETRY_IMPACT.csv`）。
备选 E-B（收窄收益）要给 `WeaponHit.Apply` 加来源区分，改判定签名、削弱已有构筑，不推荐。

### 2.4 七武器的构筑差异与真实 Player 验证矩阵

**[推] 两个 R 梯队**（`CALC_MODEL.md §5.1`）：长剑/法杖/弓 `2.000 ×P/s`；长枪 1.923、双刃 1.878；**巨剑 / 镰刀只有 1.000**，是长剑的一半 —— 它们靠 65°/85° 扇形与 2.6/3.0m 距离换多目标覆盖，不是靠倍率。P02「巨剑单发最高」是事实但容易误读。

`WEAPON_BUILD_VERIFICATION_MATRIX.csv` 给每把武器两套构筑（稳定 / 高风险），每套写明：
- 槽位顺序、独占机制、有效距离带、主要风险；
- **真实装备获取路径**：旧武器走 `AdventureLoadout.Craft`（`:177`）需真实材料；新武器走训练装备架按钮 → `SpawnTrainingArsenal` → 真实拾取（`NewWeaponCombat.cs:35`、`WeaponSkillPanel.cs:6`）；
- 训练场 Run（技能释放）与三地区远征 Run（装备获取与实战）**分开计**，不能用训练场代替远征；
- 逐 Run 必需断言（含 `skill-release`、`pierce-contact×N`、`guard-broken`/`control-immune`、`zero-damage-assert` 等）。

### 2.5 三把新武器的品质专属提案

**[源]** `WeaponTraits.Exclusive`（`:10`）对三把新武器统一返回说明文字，**无任何品质专属**；而 4 把旧武器紫起就有剑气 / 余波 / 侧球 / 加箭。
`QUALITY_EXCLUSIVE_PROPOSAL.md` 给 9 条提案（每武器紫/金/红各 1），**只复用已存在的参数族**（段数、半径、距离、时长、倍率、追加一次同类型判定），其中：
- 6 条 L1 数值；
- **2 条 L2（双刃紫、巨剑红）需单独授权**；
- 1 项「品质参数是否参与回响叠乘」的决策待拍板（巨剑金波会叠到 0.525m/12.5m、镰刀金牵引会叠到 7.0m）。

## 4. 三个结构性发现（模型算出，不是设计想象）

1. **七武器普攻分两个 R 梯队** —— 巨剑/镰刀 1.000 vs 长剑/法杖/弓 2.000。
2. **8/14 扩展技能 B<1** —— 严格劣于「同窗口一直普攻」，根因是 `W` 不是倍率。
3. **品质缩放不对称** —— 槽 0 白→红 D 增长 1.73–2.13 倍（红弓 η=1.700），14 项扩展技能全部不吃品质。**装备越好，差距越大**。这比倍率差更根本。

**因此 03A 的结论是「让扩展技能在独占场景成立」，不是「把倍率对齐」。**
