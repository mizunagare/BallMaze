## 数据与查询入口

`RouteScoring.Evaluate(session)`返回每个POI的RouteEvaluation，含可达性/完整路径及状态、当前目标匹配、预期材料向量和装备数、归一化收益、撤离选项/便利度、来源新颖度、距离成本、风险原始计数/归一化分项、总分和排除原因。`Ranked`只排序eligible项，分数相同时按稳定POI ID排序。HUD从同一结构投影，不另算评分或费用。

先检查完整NavMesh路径，再检查实际启用出口实例。不可达记录距离-1与NO_PATH；没有完整可用撤离路线记录NO_USABLE_EXIT。它们总分保持0且不能参与排序，不伪装成零距离、低风险或有效建议。出口缺料/接近点不可用/无出口路径分别记录原因。

分项数值只在`reachable && exitAvailable`时有定义；前置门槛失败时的默认数值不能解释成世界没有敌人/收益或风险为零，应按排除原因显示不可达/无出口。目标不匹配等后续排除项仍保留已计算分项用于核对，总分0仍不参与排名。

出口FREE、REPAIRED可计划使用；REPAIRABLE只表示当前随身材料满足原B1木石费用、仍需亲自靠近修复并完成原子保存；MISSING_MATERIALS不算可用。仓库材料与预期将采材料不能用来替玩家垫付。查询不调用RepairExit或BeginExtraction。UI清楚标需修费用/已修/免费，取消撤离等仍沿用原流程。规划可用不等于此刻已靠近、未受击或保证撤离成功。

## 集中配置与公式

完整首轮All执行中，源码审计发现旧空结果文案仍宣称“可撤离后再次出征/免费出口始终可用”，与NO_USABLE_EXIT矛盾。这是源码审计FAIL，不伪称首轮已有该UI断言失败。现已让UI使用同一次Evaluate的数组同时排序和生成无路径/无出口/无财物来源提示，并增加实际无出口展示断言；首轮完整结果保留为非最终，修复后新目录完整All另跑。

唯一配置位于`Assets/CombatPrototype/Resources/RouteScoring.json`，version1，启动加载校验，缺失/未知版本/非有限/负值/零参考值拒绝。无静默替代参数。UI和评估器没有独立权重表。

`总分 = 80M + 30Y + 15X + 10V − 20D − (12A + 12P + 25E)`。

总分可以超过100或为负，不是百分比。仍有技能祭坛等非财物事件时，本版没有为技能效用造价；NO_REMAINING_YIELD在本评估器中表示没有剩余材料/装备财物来源，不宣称整个地点已无任何玩法。

| 分项 | 首版定义 |
|---|---|
| M 目标匹配 | 制造各缺口可由地点期望材料覆盖的数量之和 / 总缺口，逐种类最多覆盖该种缺口；含B2真实前置解锁费用。目标已齐时为0，不除零、不虚构缺口。无制造目标时按实际出征目标投影（采集按材料量，寻宝按未开箱/地面装备，讨伐按存活遭遇）。 |
| Y 预期收益 | clamp01((期望材料件数 + 8×期望装备数)/40)。8是排序用装备等价分，不是实际材料奖励、装备售价或品质保证。 |
| X 撤离便利度 | 在可用出口中选成本最低者；X=1/(1+出口成本)。成本=地点至真实互动接近点NavMesh长度/100 + 实例引导时长/10 + 未修且可付费时0.25。这里只使用配置的引导时长，不预测中断或ETA。 |
| V 来源新颖度 | clamp01((存活资源节点+未开箱+存活遭遇)/(原节点+原遭遇+该地点宝箱数))；分母0时0。明确显示为“未完成来源比例”，不是未实现的到访、视野或新地图记忆。地面残留不算新探索来源。 |
| D 距离成本 | 角色当前位置至地点的完整NavMesh路径三维corners长度/150，不用图边长、不截断远距离成本。零距离合法。 |
| A 目的地风险 | clamp01(该地点当前存活遭遇数/4)。不要求打光这些怪，也不宣称是受击概率。 |
| P 路径近敌 | clamp01(当前存活敌人中靠近路径者数量/4)。单点零长度路径也检查端点。 |
| E 精英贴近 | 路径近敌中有存活精英取1，否则0，不随精英数量无限叠罚。 |

“靠近”统一使用敌人当前坐标到路径线段的水平距离 < 该敌人当前detectionRange + 配置buffer4米。只读查询实际敌人和位置，未加入天气/陷阱/不存在系统的伪分项。它是局部风险代理，不模拟视线、移动预测、警戒后的追击上限、玩家技能配装或胜率，不能称“安全路线保证”。同一敌人同时贡献目的地和路径风险是本版明确的两项成本，不是意外的重复掉落计数。

可绕行距离仍来自排除静态哨站导航区的完整路径，不能保证避开离巢敌人；不是把森林改为必经精英的迷宫。绕行不自动移动角色，也不替换默认路径分数，数据明确区分。

## 收益来源与随机纯读

宝箱区间由ForestRewards.ChestRanges统一驱动实际抽取与期望计算，维持原材料顺序、上下界和随机抽取次数；ShouldDropChestGear与遗迹必出边界未修改。旧宝箱区间也共用定义。节点按原3～6均值4.5加当前真实采集加成；敌人按原皮料区间均值、实际晶石数、原掉装概率及哨站精英原2～4晶石均值3；地面材料/装备按实际数量。已耗尽/已开/死亡对象不再预测未来奖励，未拾取物仍是地面来源，不计入库存或仓库。没有预抽装备品质/词缀或提前兑现期望值。

查询不保存、不改本局/永久状态/来源账、不改变Rewards/Placement/Events或Unity全局随机状态。几何路径和出口接近点只用短时内部缓存。为满足同状态完全一致，路径缓存以精确起终点匹配，废止上轮2米近似起点复用；几何/实体变化失效，1.5秒有界刷新。原HUD详情0.25秒刷新且暂停世界，紧凑HUD不每帧跑完整评分。重复查询、缓存失效强制重算及新进程同检查点均核对完整评估JSON。
