# UX-PROGRESSION-01 · 可量化验收标准

> 验收分两部分：**A. 本批设计交付验收**（现在就能判）、**B. 后续实现阶段验收**（每个阶段的门槛）。
> 所有判据都是"可复核"的：要么是文件/哈希事实，要么是源码只读检查，要么是真实 Player run 的断言。
> 无法自动判定的（观感、手感、可读性）单列为 **C 类人工评审**，且默认 `NOT_RUN`，不得用推断代替。

## G. 度量口径说明

1. **"100%"** 表示穷举而非抽样（如 7/7 武器、9/9 目标卡）。
2. **"逐帧一致"** 指同一帧内读取的进度与真实计数相等；允许 UI 刷新延迟 1 帧，但断言必须读同一帧。
3. **"零改动"** 指 `git diff --numstat` 在保护路径上为 `0 0`。
4. **"可复现"** 指同一存档、同一构建、同一输入序列，两次运行结果一致。
5. 所有 Player 证据必须带 `runId/processId/buildSha`，并按 `Evidence/` 规范归档。
