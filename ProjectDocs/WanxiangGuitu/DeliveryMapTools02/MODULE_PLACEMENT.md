# 自有模块、碰撞和导航

自有资源：Column.prefab、Arch.prefab、ArchMesh.asset、RoadMesh.asset及封闭遗迹房间。8根石柱，带真正墙/屋顶Collider的16×18m遗迹，4m前门开口（拱内净宽约3.4m），通过保存的Prefab实例与模块参数布置。没有Dungeon Architect代码或付费MapMagic对象节点。

封闭空间使用明确的地板、四周墙体及屋顶；墙体侧向Raycast和屋顶向上Raycast均验证第一碰撞。NavMesh按实际Collider烘焙，半径0.65m、高度2.5m的原型敌人通过门口。水域Box标为NotWalkable，水中导航采样失败，直线NavMesh射线被阻挡，合法路径绕行。

湖泊路径首次断言失败的原因是测试采用了无限高二维矩形：原始轨迹处于约5m高的干燥岸边，而阻挡体顶面为2.5m。没有移动目标、关闭Collider或放宽深水标准；当前分别验证实际三维碰撞体（含代理水平安全扩张）及圆形水面，并有深水拒绝/高岸允许对照。旧FAIL和轨迹不覆盖。

早期技术图还暴露路面三角绕序朝下、地板顶面贴近Terrain、原型胶囊默认Shader不兼容。修正仅限新建实验资源：路面向上、地板提高0.3m（顶面2.3m）、共享URP材质；地形高度哈希不变，NavMesh重新烘焙，实验内容身份升级为MT02-world-v2。Refine1保留修改前Scene/路面资产副本。最新生成工具直接产生修正后的布局；Refine只用于旧v1实验场景一次升级。

场景资源是技术验证夹具，不是最终遗迹美术或正式新地图。当前只证明有限模块的真实通行、遮挡、保存/加载和资源生命周期；复杂地下城语法、可交互门事务和产品Boss战没有在本批实施。
