## 玩家实际入口

1. 打开 ForestRuins 场景并 Play。新档进入暂停的营地仓库；有效旧档继续原本的遗留冒险。
2. 在“营地仓库”中存取、制作、解锁，点击右上“出征准备”（营地按 H 或点关闭也会打开准备，不直接进入战斗）。
3. 查看两把武器、容器、全部装备、六材料和药水携带清单，选择模式，点击“确认出征”。保存失败会退回营地，不创建第二个 Run。
4. WASD 移动，Shift 奔跑，左键普攻，F 武器技能，V 切换，空格翻滚，E 交互，Q 药水，Tab/B 背包，C 角色。
5. 清完当前波次，先拾取掉落，回起点蓝色柱形装置附近（坐标 0,0.1,-10，范围 3 米），关闭背包后按 E/H。引导默认 3 秒，可在 AdventureFlow 参数调整。引导期间暂停下一波；受伤、走远、再次 H 均取消。
6. 结算页先预览，再“确认结算并保存”，最后“返回营地”。死亡和 R 主动放弃走同一结算边界，主动放弃需要二次确认。
7. 仓库满时到营地“待领取”页领取到合法位置，或明确确认弃置。未处理完禁止出征，退出后仍可继续处理。
8. F5 保存当前完整检查点，F9 读档；关闭游戏保存检查点，下次继续同一个 Run。正常退出没有奖励，也不会自动出征。

有限“测试挑战”默认目标为第 5 波首领战。由真实敌人死亡事件判断完成，停止后续波次；玩家拾取后仍需撤离，结果为“测试挑战完成”。另一入口“无尽波次”会继续第 6 波及后续每五波 Boss。ForestRuins 仍是波次测试场景，没有正式森林灵徽、区域解锁或五区域通关声明。

## 冻结的保留规则

| 对象 | 成功撤离/测试挑战完成 | 死亡/主动放弃 |
| --- | --- | --- |
| 永久仓库、历史配方 | 保留 | 保留，不整档回滚 |
| 入场非消耗装备/胸挂/背包 | 当前实例固有修改保留，按入场布局归还 | 按入场实例快照及布局归还 |
| 新装备（含本局制造） | 剩余持有的送仓库，满仓进待领取 | 丢失 |
| 本局新增材料 | 剩余量送仓库，容量不足进待领取 | 丢失 |
| 带入材料/药水 | 只归还剩余量 | 只归还带入剩余量 |
| 局内制造的药水 | 剩余可带回 | 丢失 |
| 等级、三选一、祭坛临时技能 | 清除 | 清除 |
| 本局永久解锁凭证 | 成功计划中提交 | 不提交 |

先花本局来源，再花带入来源；制作消耗与药水使用都走来源账目。入场装备冒险中禁止拆解，后端也拒绝。入场武器可铭刻：死亡恢复旧词缀，但晶石成本不返还。升级、祭坛的临时属性不写入装备固有词缀。

成功也恢复入场容器布局，避免当前穿戴的新容器移入仓库后让原布局失效。主副武器优先保留当前有效的入场武器选择；新武器带回仓库后可取回配装。

## 数据与事务边界

- `ProfileState`：唯一有效的营地配装、仓库、材料、配方、待领取、已提交 RunId、预留徽章/区域。
- `RunState`：唯一活动 RunId、ForestRuins/模式、种子与生成版本、目标、阶段、完整世界检查点、材料/药水来源、入场快照。入场快照只是恢复参考，不是第二件物品。
- `SettlementRecord`：`RunId:terminal`，唯一终局、冻结明细、确定性的 Profile 计划、Pending/Committed 与页面确认状态。
- 一个 v7 完整封装统一写盘。每次保存先校验、写临时文件并 Flush(true)，再 File.Replace 维护备份。所有有效位置检查实例 ID 唯一；计划/入场快照不算有效所有者。
- 终局先写 Pending 日志，后在一份完整保存里更新 Profile、标记 Committed、清除 ActiveRun。只有提交成功才装载营地；失败保留 Run/计划，页面允许重试。回营装载失败也保留已经提交的结算，不再次发奖。
- 同一更新内死亡优先，由高执行顺序的协调器 LateUpdate 统一裁决；后来的事件不能覆盖已锁定结局。
- 待领取使用固定来源 ID，不能直接提供属性、制作或拆解；领取/弃置与所有者变动一同保存，失败回滚。
- 仓库存取、配方解锁、制造继续采用既有营地提交边界，活动冒险禁止直接向永久仓库写货。

## 检查点与边界

运行中 HUD 显示最后成功保存修订号、波次和人物位置。默认 5 秒自动保存；出征、撤离开始/取消、终局、结算、营地变更单独保存。正常退出主动保存，不把退出回调当唯一保存机会。

同一份检查点包含人物、技能、背包、来源账、敌人血量/波次、事件使用状态、采集节点、地面掉落和 Unity 随机状态。恢复后飞行弹体、攻击前摇等瞬时动作清除；界面明确提示，未承诺逐帧回放。强退可能回到最后一次成功写盘，不保证未保存步骤。种子字段用于后续扩展，本批没有种子森林地图。

只对产品正常流程、备份恢复和故障重试提供一致性；不防止手工篡改/复制/回滚存档。
