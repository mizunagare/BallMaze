# 首版参数与平衡边界

本表是独立新配置，不覆盖旧四武器或CP06-A八技能。不是最终平衡结论。基准中性训练攻击力33；实际品质/词缀/成长仍走原伤害入口。

普攻时钟乘 `(疾风?.82:1) / Frenzy.AttackSpeedMultiplier`，包括间隔、前摇、恢复和动作采样时长。普攻触及增加既有Reach加成。技能不吃Frenzy；回响按原语义扩大技能实际范围，地波半径/距离与牵引距离同步25%，实际视觉边界使用相同参数。聚能仍由WeaponHit增加主动伤害25%、公共技能CD增加1秒；其他伤害/汲取/猎首沿原入口。Boss控制免疫。所谓破防是可观测的短时攻击中断/恢复门控，不削改原护甲公式。

三种新武器并不依赖提高普通敌HP/伤害。巨剑固定蓄势，不是新增长按蓄力条；双刃反击不是空翻滚自动增强；镰刀基础及每段技能有方向，不是全屏/无条件360度。没有新增攻击位移。

新增掉落是追加供给，详见[DROP_RULES.md](DROP_RULES.md)。普通3%、精英8%、每次最多1件、Boss不追加，三武器等权。若全部拾取并分解，现有1..5铁矿规则的理论条件期望为每件1.775铁矿；此为公式推导，不是实测经济收益，不计死亡、满包、保留和装备价值。没有出售价格系统或统一货币估值。没有用减少旧掉落补偿追加供给。

现有受控样本用于机制正确性，不足以证明武器胜率、持续DPS、手感或成长平衡。独立人工试玩、同种子构筑对比和长期经济样本等待复审后明确安排，不在本批伪称完成。
