# 猫族角色规范 v1

黑猫冒险者：短厚身体、明显猫耳与尾巴、浅口鼻、琥珀眼、红围巾、帆布包、皮革带与冷色金属护甲。模型使用偏蓝黑而非纯黑，保持脸部对比。普通敌、精英和首领分别用轮廓、肩部体积、枝角/鳍耳区分，不依靠颜色一种信号。

CatWorldArt 是原创几何定义，CatWorldBake 生成真正的Mesh/Material/Prefab。CatActorVisual 将刚性部件绑定已有 KayKit 骨骼，继续使用已有 CC0 动作剪辑与 FantasyActorVisual 时钟；不是新制作的柔性蒙皮或面部动画。Idle/Walk/Run/Attack/Hit/Death沿用原动作，Dodge为程序化。动画不决定伤害或冷却。

14种外观包括主角、盗匪、斥候、蘑菇猫灵、树灵猫、猎手、猞猁、陆地/湖中首领及5种设施猫。设施猫为静态角色代理，未新增行走、对话和交易系统。野猪模板项以猫科森林兽替代，不额外创建新敌人战斗类型。

四武器保留原挂点、枚举、技能、攻击窗口和奖励语义。Boss仅改显示名/网格/材质，forest:warden与forest:tide及存档标识不改。尚无新表情、柔性尾巴与独立NPC动画；不得描述成完整新骨骼动画资产包。
