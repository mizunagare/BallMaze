# 普通掉落审计

| 产物 | 固定规则 | 验证 |
| --- | --- | --- |
| 白色普通装备 | 广场箱按旧身份散列条件决定 | White 首轮 18 次仅出现 1 次，未达样本门槛。WhiteRetry 保持原门槛，用 9 次真实新 Run 观察到 2 个不同普通装备 ID |
| 绿色优良装备 | 地下隐藏箱 | Green 两个新 Run 均沿实际路线开启隐藏箱，分别得到不同绿色装备 ID、铁矿 3 和晶屑 2，同档案仅一条永久遗镰回执 |
| 紫色史诗装备 | 守护者常规装备 | R2Boss 和 R2ResumeBoss 在不同 Run 真实击杀，首奖仅一次，常规装备与材料重新出现 |
| 铁矿与晶屑 | 广场矿 1–3、晶屑 1。隐藏箱矿 3、晶屑 2，另有碑文晶屑 | 实际交互和地面记录，抽样期间验证旧随机流不变 |
| 兽皮、晶屑、核心 | 守护者 4、3、1 | 实际地面拾取、恢复后检查和下一 Run 重掉 |

R2ResumeBoss 与 LoadElite 在已死亡实例上重复调用既有掉落入口，验证地面身份和数量保持。普通装备不进入永久唯一账本。首轮白色样本及每一局的种子和产物保留。样本用于证明可重复取得，对旧概率和平衡没有统计结论。水晶以产品实际物料「晶屑」记录。其他地图各品质与全量概率未枚举。
