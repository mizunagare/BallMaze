## 2. L1 · 12 项 T1/T2 技能的收益与代价规格

### 2.1 模型、目标带与统计口径（R1 统一）

公式保留（见 `CALC_MODEL.md §2`）：

```
B = D / (R × W)             窗口内爆发系数
η = 1 + (B − 1) × W / C    相对纯普攻的持续效率
```

| 带 | 适用 | 门槛 | 数量 |
|---|---|---|---|
| **T1** | 无独占机制的纯输出技能 | `B ≥ 1.10` 且 `η ≥ 1.01` | 1（`sword.triple`） |
| **T2** | 有独占机制的输出技能 | `B ≥ 1.00` 且 `η ≥ 1.00` + 至少一个场景优于槽 0 | 11 |
| **T3** | 条件触发 / 纯控制 | **不使用 B/η 作目标判定** | 2（`twin.counter`、`sc.pull`） |

**统计口径（R1 硬规则）**：

- 14 项总数保留；**T1/T2 = 12 项**，是唯一使用 B/η 的范围；
- T3 = 2 项（条件反击 1、纯控制 1），其 B/η 只保留在 `SKILL_VALUE_MODEL.csv` 附录列，
  `metric_status = APPENDIX_ONLY (T3)`、`target_check = N/A (T3)`，**不得计入通过率**；
- **`8/14 B<1`** 是「全 14 项（含 2 个 T3）」的计数，**不代表 8 个输出技能弱于普攻**；
- **`6/12 B<1`** 才是 T1/T2 输出技能的现状计数，由脚本重新生成并断言；
- 通过只能称 **`MODEL_PASS`**（离线模型落入目标带），**不是真实战斗通过**；
- `cap` 与 `H` 是**理论假设，非 Player 实测**；主模型 `N=1, H=1.0`。

`MODEL_SUMMARY.csv` 逐项列出这些计数；`build_balance_model.py` 在生成时以 `assert` 强制
`total=14 / T1+T2=12 / T3=2 / B<1_all=8 / B<1_T3=2 / B<1_T1T2=6 / MODEL_PASS=12`。

### 2.2 模型边界（不是完整实战 DPS 模拟）

| 假设 | 说明 |
|---|---|
| `W` | 技能占用且不能普攻的窗口，由 `startup/gap/charge/recovery` 按源码时序算出 |
| `C` | 冷却**从施放开始**计时 |
| `C ≥ W` | 冷却不短于窗口（脚本逐行 `assert`） |
| 冷却剩余 | 按**纯普攻输出**填满，是保守下界 |
| 不考虑 | 两个技能交替、敌人移动、遮挡、打断、目标死亡溢出、控制收益 |
| 不混算 | 控制收益、AOE 覆盖、贯穿、命中可靠性**不折算成单一等效倍率** |
