# 《万象归途》黑猫猫族世界：资产清单模板（给 Codex / 美术接入使用）

本文件用于配合 B10 任务书与《黑猫猫族世界_概念提示词包.md》使用。

用途：
1. 让 Codex 按模块制作、替换和接入资源。
2. 让美术 / 出图 AI / 资源整理过程有明确目标。
3. 让最终验收时可以对照“概念设计 → 实际资源 → Unity 接入 → 运行证据”。

---

## 一、状态定义

每项资产统一使用以下状态：

- `CONCEPT_ONLY`：只有概念设计，还没有实际资源。
- `CREATED`：实际资源已制作，但未接入 Unity。
- `INTEGRATED`：已接入 Unity，但未完成运行验证。
- `VERIFIED`：已接入、已验证、证据完整。
- `BLOCKED`：因兼容、来源、技术或时间问题阻塞。

---

## 二、字段模板

每项资产建议记录以下字段：

- Asset ID
- 资产名称
- 分类
- 子分类

- 实际资源路径

- 使用场景 / 界面 / Prefab
- 来源与许可
- 原始文件 SHA256
- 导入设置
- 当前状态
- 验收证据路径
- 已知问题
- 负责人 / 生成方式

## 四、给 Codex 的实际执行要求

你可以把下面这段附给 Codex：

请以本资产清单模板为基础，在 `ProjectDocs/WanxiangGuitu/DeliveryB10/ArtBible/ASSET_CATALOG.md` 中建立《万象归途》B10 的完整资产表。B10 的统一方向为“黑猫主角 + 猫族营地 NPC + 猫科主题敌人与 Boss + 立体卡通材质 + 简洁清晰 UI”。请对每个资产填写 Asset ID、概念来源、Unity 接入位置、当前状态、验收证据和已知问题。不要只制作概念图，必须将优先级高的主菜单、HUD、背包、主角、NPC、普通敌、Boss、营地、森林和图标真实接入 Unity，并在 `VERIFIED` 之前保留真实状态。
