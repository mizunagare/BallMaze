# R1 排序规则

- 唯一入口为 `B2InventoryQuery.Apply`：先执行共享筛选，再生成排序后的新列表。
- 默认：保持输入原始顺序。攻击：降序；品质：降序；类型：枚举升序。相同值按装备唯一 ID 的 Ordinal 升序确定稳定次序。
- 两 UI 的排序按钮循环：默认 → 攻击↓ → 品质↓ → 类型 → 默认；不修改已有热键。
- 两 UI 渲染同一过滤后排序目录；目录可滚动，不以网格的绘制迭代顺序冒充物品位置排序。网格是空间装备容器，仍保留真实坐标和拖放语义。
- 不写入底层容器顺序、ID、主副武器、位置或收藏；装备盘保留原有全展示，背包使用完整筛选规则。
- 实体“整理背包/整理仓库”与只读“显示排序”分别验收，前者继续使用既有空间整理/存储事务。
- 最终证据以 [验收矩阵](<PLAYER_RUN_MATRIX.csv>) 和 [证据索引](<EVIDENCE/INDEX.json>) 为准，本文不是 PASS 凭据。
