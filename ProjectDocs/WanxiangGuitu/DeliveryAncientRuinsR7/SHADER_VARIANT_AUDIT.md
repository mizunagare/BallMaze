# Shader Variant 实际提交核查

Windows 非开发 Player、RTX 3060、D3D12、1280×720。A/B 各用两个独立进程采样重复每个机位。取证程序集固定镜头后给出采集窗口，D3D12 探针记录命令列表的 PSO 绑定及 DrawInstanced、DrawIndexedInstanced，并以 ExecuteCommandLists 将记录限定到提交队列。Unity 原生描述符钩子在 PSO 缓存读取或创建前取得各着色器阶段的实际字节码，结合 D3D12 直接创建钩子，以 SHA256 对 stage tuple 去重。窗口覆盖稳定机位下的连续帧，非单帧逐像素 GPU trace。[描述符调用位置](Evidence/Audit/player-descriptor-excerpts.txt) · [探针源码](Tools/Trace-D3D12.js)

最终 112 个采集窗口内的提交绘制均关联了阶段指纹，未出现未知 PSO。A/B 比较的是实际提交的字节码组合集合。记录保留 draw 计数和提交次数，采集窗口时序存在差异，计数无需逐项相等。阶段组合为真实二进制身份，ShaderLab 同名关键字和互相共享的阶段代码不能据此反推为唯一源码变体。[所有窗口、真实指纹和计数](Evidence/Audit/gpu-and-post.json.gz)

**包内与运行记录分列。** 两包的 65 个 Shader 序列化对象同哈希。只读解压其中 Direct3D 平台段，通过容器头、长度、块表和代码块类型校验，识别 490 个去重 DXBC 容器指纹。28 组机位×状态、每组 A/B 共 4 个采样中，提交绘制实际用了 30 个去重阶段字节码，其中 27 个与包内容器精确匹配，3 个在此包内扫描中无精确匹配，仍保留真实提交指纹。另有 463 个包内容器指纹在本矩阵未被观察到。此计数单位是编译后二进制容器，非 ShaderLab 关键字组合总数。[包内清单](Evidence/packaged-shaders.json.gz) · [匹配表与未观察列表](Evidence/Audit/gpu-and-post.json.gz)

观察覆盖本次固定场景、可识别的 D3D12 提交路径、当前硬件和图形设置。两包使用了相同的观察到的变体集合。未对所有可能玩法状态、其他 API 或所有 ShaderLab 名称建立一一映射。
