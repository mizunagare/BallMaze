# CP06-C1-R1 奖励规则

遗迹 R1 分离永久收录与单局掉落。角色档案保存特殊奖励身份、首次获得的 Run ID 和领取状态。只有主动新建五区遗迹 Run 时写入 ruinsR1。v9 缺省值为 false，旧在途森林、三区遗迹和五区遗迹继续使用原规则。

| SpecialRewardId | 获取动作 | 永久权益 |
| --- | --- | --- |
| c1.special.artifact | 开启地下隐藏箱 | 紫色回响遗镰，营地待领取 |
| c1.special.guardian-first | R1 规则下首次击败守护者 | 紫色守护者初誓巨剑，营地待领取 |
| c1.special.chronicle | 解读地下碑文 | 祭坛残卷，永久收藏 |
| c1.special.collector-seal | 开启石柱广场宝箱 | 纪念印，永久收藏 |
| c1.special.gate-key | 激活广场符文机关 | 机关钥，永久收藏。每次新 Run 仍须激活本局机关 |

特殊装备始终先到营地待领取区。玩家在营地选择背包或仓库，容量不足则原样保留待领取记录。永久回执独立于实际装备的所有权，背包移出或拆解装备后仍存在。特殊待领取禁止弃置，也不会单独阻塞再出征。已有档案在首次进入新版规则前的历史击杀不补发首奖。正常保存、继续和区域重载使用同一回执。外部恢复整套更早的存档文件属于快照回滚，未建立外部防回滚账本。

触发事件保存使用现有的版本校验、原子发布和已发布确认机制。普通地面产物、事件标志与新增永久回执同次写入。领取复用营地事务，永久回执、物品位置和待领取移除同次写入。守护者真实死亡在同帧创建普通掉落和首奖回执，下一检查点保存。保存失败时保留本次内存结果供重试，原检查点则仍代表之前未完成的击杀。撤离、死亡或主动放弃继续由原有终态流程结算。

普通奖励使用原有 Run 加区域和事件身份。同局重复交互和死亡回调维持幂等，新 Run 按原规则重新取得。守护者的常规掉落仍为兽皮 4、晶屑 3、首领核心 1、紫色武器 1。首奖装备是额外供给。其拆解和仓储仍适用现有装备规则。特殊装备工厂使用固定档案与奖励 ID 派生，保留既有旧流与掉落抽取顺序。
