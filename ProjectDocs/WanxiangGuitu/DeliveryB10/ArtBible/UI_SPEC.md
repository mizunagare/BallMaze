# 猫族 UI 规范 v1（实施中）

暖米色信息、深灰蓝底、灰蓝操作面、奶油色选中；错误保留红色短句与原始失败原因。图标来自 CatWorld 原创三维模型摄影，文字使用中文系统字体回退。不得用 Emoji 替代功能图标。

TitleMenu、PlayerHudPresenter、CatInventoryPresenter 共用 CatUI 颜色与字体。uGUI CanvasScaler 参考1280×800、Expand；菜单居中安全边距，物品详情与容器分栏。24/32/48/64/128像素图标仍须单独检查，不因原图256像素而视为全部通过。

常驻生命/武器/技能/唯一目标；情境交互/预警/撤离；完整配方、路线、属性、帮助按需展开。保存失败和结果待核对优先于普通通知。装饰图与蒙版不拦截射线。

背包格子绘制真实 occupiedCells，拖放、旋转、交换调用原容器业务；页面切换立即使旧回调失效。材料采用原计数制，不虚构材料占格。当前仅一个自动存档，不提供虚假的槽位。模板任务物品类没有业务物品时必须显示空态，不生成假任务。

所有受控回调、截图与原生输入分别记录。可读性最终仍需独立人工试玩，不以自动截图取代。
