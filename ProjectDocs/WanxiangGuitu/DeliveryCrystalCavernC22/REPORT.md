# CP06-C2.2 隐藏矿室与晶核精英

从 `093d0bfebd33747d4a2b035b22b26a701778a8ca` 建立独立分支。该版本作为带开放项的 C2.1 三区域内部开发检查点。C1 R7 的 7 PASS / 1 FAIL / 2 NOT_RUN / 2 UNRESOLVED 保留。历史发行语义等同性、GraphicsSettings 写回因果、三个未匹配指纹与严格像素失败沿用原记录。

## 实现

- 矿脉区西侧增加独立门、实体岔路和有顶矿室。青色晶纹引导玩家找到可交互机关。封门时实体门和 NavMesh 一起阻断，开启后可实际往返。矿料箱使用正常掉落与拾取；新 Run 可重新获得普通奖励。
- 晶核精英复用遭遇导航、伤害、翻滚、错峰、死亡和掉落设施。新状态包含晶壳、扇形预警、晶核暴露和恢复。预警或放电范围内有释放二次检查，能量区两侧可绕行。真实受控样本中冲击使玩家从 100 降到 77，同一把剑分别造成 14.85 和 37.95 伤害。
- C2.2 使用布局修订 8、生成版本 11 和单独固定 Prefab。旧 C2.1 继续修订 7、生成版本 10 和原 Prefab。v9 复用事件 used 和敌人快照。旧洞窟、森林、遗迹在途档在两套运行时均验证恢复。
- 新素材由仓库内编辑器工具生成，包括固定空间、晶纹导向、晶簇与 URP Lit 材质。晶核精英复用现有角色与预警渲染。实机截图使用当前发行包的受控观测副本。角色在近距离能遮住部分预警线，人工可读性保留 NOT_RUN。

## 验证

C2.1 冻结发行包的隔离观测副本补测 5 次，96 PASS / 0 FAIL。C2.2 Editor 17 次，253 PASS / 0 FAIL。C2.2 非开发测试 Player 17 次，260 PASS / 0 FAIL。两套运行时分别覆盖七武器各两项真实活体命中、矿室开关与存档、跨新 Run 普通宝箱、精英阶段与掉落、能量通道、双材料真实结算，以及旧入口和旧存档。选定运行的统计与原始失败分列。

纯发行 Windows64 使用 Unity 6000.6.5f1，BuildReport 0 错误、105 警告。Development=false，Bee 五项诊断服务关闭，程序集与登记表无验收驱动。真实标题出现，私有桌面后台关闭后进程正常退出，合成存档未改变。Build 退出的 JobTempAlloc 警告仍开放。警告摘录与全量日志哈希已归档。

隔离工程首次打开自动生成 `Assets/Resources.meta`，内容为 DefaultImporter 文件夹元数据。构建前后哈希一致。扫描的 Unity 文本资产与配置未发现对其 GUID 的序列化引用。七份新材质在本次 Unity 流程将旧兼容属性 `_Color` 规范化为基色近似值，`_BaseColor` 保持原值。提交使用已构建副本中的规范化材质，并保留第一次 Bake 版本与差异的哈希记录。此处没有重启双包等同性调查。

项目用户场景、ProjectSettings、原本未提交的恢复文件、历史结果与真实存档保持受保护。CombatAim、TargetAssist、镜头、既有武器数值与旧技能未改。纯发行证据与观测副本证据分别归档。
