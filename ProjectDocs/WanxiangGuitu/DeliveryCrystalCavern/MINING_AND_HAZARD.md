# 矿脉与能量危险区

两处矿脉沿用 AdventureResource。武器真实击中后扣节点生命，归零时使用当前 Run 的已有奖励随机流和采集加成生成铁矿或晶石。掉落通过 InteractionResolver 走正常拾取、容量检查和来源账。普通奖励随新 Run 重生。C2.1 沿用常规敌人掉落，未引入特殊奖励、材料枚举、配方或制造规则。

能量通道稳定 ID 为 c2:energy-pulse。周期为恢复 3 秒、琥珀预警 2 秒、红色放电 1.25 秒。可见地面范围与轴对齐触发体同宽。实际伤害判定要求英雄位置在体积内，发射中心到英雄无实体阻挡。本次放电最多一次接触，使用原 CombatHealth 入口和已有减伤、翻滚无敌规则。离开范围、墙后、恢复与预警均无放电伤害。暂停冻结计时。死亡阻断继续判定。卸载解除所属 Run 并恢复相位。新进程的短时脉冲重启于安全恢复窗，矿脉状态独立保存。以上数值为原型候选。
