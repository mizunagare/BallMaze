## 脚本失败与修复记录

- 容器旧测试缺少新增营地制造前置；双武器测试路径参数化后漏复制 v3 样本。补齐隔离夹具后复跑 PASS，未为旧测试放宽产品规则。
- B05EditChecks 同步方法返回但不退出 Editor，实测超时 240 秒，退出码 -1，汇总失败；增加 QuitMethods 后实际 exit 0。
- 最终严格 ID 校验暴露 v1～v6 事件缺 ID 的产品迁移问题。恢复旧事件时一次性赋 ID，重跑迁移/双武器/异常档和 v8 四态均 PASS。
- Runner 自检故意执行 exit 0、exit 7 和 1 秒超时：实际 [0,7,-1]，汇总 failed=2/timeouts=1，脚本退出 1。它是失败检测验证，不冒充三个成功测试。
- 首次独立程序恢复到了同一局，但入口角色位置恰在 3 米半径边缘，竖直偏差使开始撤离失败（进程 exit 1）。测试驱动改为使用 CharacterController 实际向装置迈近 0.75 米后重试，不修改产品范围规则。
