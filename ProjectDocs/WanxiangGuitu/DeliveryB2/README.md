## 实际入口

在 ForestRuins 测试入口进入营地，背包“打造装备”页、“穿戴与更换容器”页或营地工作台选择模板，点击 **追踪材料**。出征准备显示目标摘要；出征后右上角显示装备图标、目标与缺口，点击 **目标详情** 查看费用与来源。**M 路线**显示地点收益和基于本局剩余实体的推荐路线；帮助面板也有“制造目标”入口。详情可滚动，HUD 的“取消目标”会保存取消结果。

| 新出征地点 | 实际材料来源 | 装备机会 |
|---|---|---|
| 伐木林地 | 木材节点；箱中木4～8、皮1～3 | 箱25%随机装备 |
| 碎岩矿脉 | 石头、铁矿节点；箱中铁矿4～8、石3～6 | 箱25%随机装备 |
| 遗迹营地 | 箱中晶石4～7、铁矿1～3 | 箱必出随机装备，不能指定类型 |
| 精英哨站 | 既有敌人皮料/晶石；精英额外晶石2～4；箱中皮5～9、晶石2～5 | 箱80%随机装备，保留既有精英掉装 |
| 湖岸物资点 | 箱中木2～5、皮2～4、晶石1～3 | 箱25%随机装备 |

固定材料池、采集节点类型与随机数量/随机装备分开。宝箱奖励全部落地，必须拾取后才进背包与来源账；容量不足继续留地面。没有自动领取、提前入仓或额外目标奖励。领主核心不伪装成森林产出，缺核心时明确提示需另行参加现有波次首领挑战。

## 查询与持久化

制造成本与实际制造读取同一个 `CraftingCosts`，装备、容器成本不变。缺口=制造费用＋尚未解锁的配方/前置链费用－随身－仓库，下限0；仓库与随身分别列出，仓库仍须手动取材。缺口查询不读入待领取物，不把地面掉落当作已拥有，不消耗随机数。重复制造时目标继续追踪同一模板，可手动取消或重新标记。

目标以可选 `ProfileState.craftingTarget` 保存，沿用 v9 完整封装、校验、备份、来源账与唯一结算，没有另造目标存档。旧档缺字段即未标记；选目标保存失败仍显示存档失败，允许原有保存重试，没有材料操作。入场、失败保护、撤离与结算规则不变。

新森林布局 revision3 / content `B06-B2` / generation5 使用新配置；旧 revision1/2 不改坐标、种子、实体、事件与收益规则，旧在途不会插入新节点。地点查询以持久化 POI ID、节点 ID、事件 ID、据点 ID 为依据，不以敌人数组下标推导。推荐会读取未耗尽节点、未开宝箱、活着敌人、未拾取地面材料；依据现有边图计算近似路径长度，不新增自动寻路或三条完整冒险路线。
