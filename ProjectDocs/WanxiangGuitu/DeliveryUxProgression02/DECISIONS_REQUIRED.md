## D-16 · 品质是否必须有代价（G1）

| 选项 | 内容 | 存档 | 代价 |
|---|---|---|---|
| A | **不加代价**，保持现状 | 无 | 「白→红攻击 16.5 倍、零格位代价」继续成立，装备追求退化为纯刷 |
| B | 代价放在**非存档**维度（高品质不可分解 / 修复材料随品质上升 / 高品质装备占用额外格位以外的软成本） | 无 | 需要新增一个「修复」或「不可分解」规则，属新规则不属新系统 |
| C | 代价放在**格位**（高品质尺寸更大） | **v10** | 已有存档中已放置的装备会在读档校验时报错，必须迁移 |

**[推] 建议 B**，理由：C 的收益（让玩家权衡）与 B 相同，但 C 的代价是让所有现有存档面临失效风险，而本阶段没有任何实测证据说明玩家已经在「无脑换高品质」。
**阻塞级别** 🔴 —— 不定则 B 方向无法进入实现。

## D-17 · 新武器（双刃/巨剑/镰刀）的获取路径是否维持纯掉落（G5）

事实：`RecipeData/` 共 29 个配方 = 9 类 × 3 品质（紫/金/红）+ 2 个容器，**武器只有长剑/长枪/法杖/弓**；`CraftingTargets.Valid` 要求 `(int)type < 9`，新武器（11/12/13）**无法被设为制造目标**。新武器来源：森林小怪 3% / 精英 8%、遗迹 2 件藏品、洞窟首领 100%（白 50 / 绿 40 / 紫 10）。

| 选项 | 内容 | 影响 |
|---|---|---|
| A | 维持 D-05（纯掉落） | 保留稀缺感；但紫以上概率 0.5%/4%/10%，「想玩巨剑但拿不到紫」无解 |
| B | 只放开**品质上限**：允许用已有材料把**已获得**的新武器提到紫（不是新配方，是「同一件装备的已知品质档」） | 触碰 D-10（单件升级）的边界，需要明确「这算不算强化」 |
| C | 加 3 个新武器配方（type 11/12/13） | 推翻 D-05 |

**[推] 建议 A 维持不变**，并把「拿不到紫」如实写进洞窟身份卡（当前只写「100% 掉 1 件」）。理由：B 与 C 都会直接削弱「洞窟首领必掉新武器」的独特性，而这个独特性是 R2 里森林/洞窟分工的唯一支点。
**阻塞级别** 🟡 —— 不影响 A 方向；只影响 B 方向是否包含「新武器成长」。

## D-18 · 「回响」是否改成对普攻也生效（G3）

事实：`WeaponHit`/`AdventureCombat` 里普攻 `Release` 不读 `area`；4 把旧武器的普攻与 8 个扩展技能对回响**完全无感**。回响当前只在「旧武器槽 0 技能」与「巨剑/镰刀/双刃的技能段」上生效。

| 选项 | 内容 |
|---|---|
| A | 保持现状，但在词缀说明里写明「仅技能范围」，把它变成一把**专用词缀** |
| B | 普攻也吃 reach（不吃 area），使回响对 7 把武器全部有效 |
| C | 回响改为「范围 + 散射 + 弹体数」三项统一 +25%（含弓的箭雨、法杖的爆半径） |

**[推] 建议 B**。A 的问题是「一个词缀只对 1/7 武器有意义」，在 6 个词缀的总量下等于削减了 1/6 的构筑空间；C 会让弓/法杖获得双重收益，破坏现有远程强度平衡。
**阻塞级别** 🟡 —— A 方向与 B-1 都需要它，但可以先做 A 方向的其他子项。

## D-19 · 存档修订窗口（复核 D-15）

本批新增两项必然触碰 schema 的内容：C 方向地区熟练度、B-2 品质格位。加上 P1 遗留的 D-01（目标回执）、D-03（技能槽持久化）、D-14（目标历史），一共 **5 项**挤在同一次修订里。

| 选项 | 内容 | 后果 |
|---|---|---|
| A | 一次修订覆盖全部 5 项（v10） | 只需一次迁移与一次回归，但任一子项未定就整体阻塞 |
| B | 拆两次：v10 = 目标回执 + 目标历史（只增只读字段）；v11 = 技能槽 + 精通 + 格位（改变性字段） | 迁移分两次，但只增字段的那次风险极低 |
| C | 不做 schema 修订，C 方向与 D-03 无限期挂起 | 与用户「地区精通仍需单独授权」一致，但意味着长期线无法落地 |

**[推] 建议 B**。理由：v10 的三项都是「只增不改」的只读记录，可以复用 P1 已经验证过的「零 schema 投影」思路；v11 的三项会改变玩家现值，必须单独评估。
**阻塞级别** 🔴 —— 它阻塞 C 方向与 D-03 的一切实现。

## D-20 · 技能槽是否持久化（复核 D-03）

事实：P1 交付的 `1/2` 热键「每局重置为默认」，`AdventureLoadout` 不写槽位。D-03 当前结论是「不持久化」。

| 选项 | 内容 | 影响 |
|---|---|---|
| A | 维持不持久化 | 每局重新选，横向构筑的「养成感」为零 |
| B | 持久化槽位**索引**（只存「哪两个技能」，不存数值） | 需要 2 个整数字段；风险极低 |
| C | 持久化 + 每武器独立记忆 | 需要 7×2 字段；收益递减 |

**[推] 建议 B**，且必须与 D-19 的 v11 同批。理由：它是「横向构筑」能否被玩家感知的前置——如果每次进局都要重选，A 方向做的所有差异化都会被抹平。
**阻塞级别** 🟡 —— 阻塞 A 方向的「跨局构筑」子项，不阻塞数值调整。

## D-21 · 结算三段建议是否允许读取目标与路线（N1）

事实（`AdventureFlow.Objectives.cs` + `RouteScoring.cs`）：三段建议只读「材料缺口（来自制造目标）+ 未完成目标卡 + 最近一次结果」，**不读路线 Top3，不读目标历史**；成功撤离后标题仍写「未竟之事」。

| 选项 | 内容 | 存档 |
|---|---|---|
| A | 只改文案与标题（「本局结果」），不引入新数据 | 无 |
| B | 允许结算读 `RouteScoring.Ranked`，把路线 Top1 作为第 ③ 段的一句话 | 无 |
| C | 允许结算读目标历史（需 D-14） | v10 |

**[推] 建议 A + B**。零存档，且直接解决「推荐不改变选择」的问题：现在第 ③ 段说的都是「还差多少材料」，而路线页说的才是「下一局去哪」。两者合并才能让建议变成可执行的下一步。
**阻塞级别** 🟢 —— 可独立小批实施。

## D-22 · 「回响/聚能」以外，是否允许新增词缀（本批禁令的边界解释）

本批禁止新增词缀。审计发现现有 6 个词缀（锐利/疾风/回响/汲取/猎首/聚能）里，**4 个是纯数值、1 个半失效、1 个代价不对称**。也就是说「构筑空间」实际只有 1.5 个有效维度。

| 选项 | 内容 |
|---|---|
| A | 维持 6 个，只修不增（修回响、修聚能） |
| B | 允许在后续批次新增词缀，但**每个词缀必须绑定一个已有机制**（破防/牵引/翻滚/蓄力），不复用纯数值 |
| C | 允许新增纯数值词缀 |

**[推] 建议 A 先做，B 作为下一阶段候选**。理由：在 6 个词缀里还有 2 个明显缺陷未修的情况下新增词缀，只会把「无效维度」从 4/6 变成 6/8。
**阻塞级别** 🟡 —— 本批不阻塞；它决定下一批的范围。

## D-23 · 地区长期线是否必须「只展示」（复核 D-06/D-07）

事实：三个地区当前都**没有**任何跨局进度；`ProfileState` 只有 `badges` / `regions` / `bossHunts` / `committedRuns` 等记录型字段。

| 选项 | 内容 | 风险 |
|---|---|---|
| A | 只展示（次数、最高纪录、收藏进度），零数值 | 与 D-07 一致；但「只展示」很难支撑「下一局还去」的动机 |
| B | 展示 + 极小确定性收益（如每 5 次该地区撤离 +1 材料掉落，上限 +2） | 触碰 D-06（持久等级）红线 |
| C | 展示 + 该地区专属制造配方解锁 | 不碰等级，但改经济 |

**[推] 建议 A，并把 B 明确列为「需重开 D-06」**。理由：任何跨局数值收益，本质上就是持久等级，只是换了个名字。
**阻塞级别** 🔴 —— 它决定 C 方向是否值得做。

## D-24 · 盘内叠加是否收敛为「主武器 + 备用衰减」（G6）

事实：`AdventureLoadout` 的 `Active.Sum(Attack)` 把盘内**所有**装备的攻击相加，因此同时放 3 把武器 = 3 份攻击。当前 UI 有「主武器」概念，但计算没有。

| 选项 | 内容 | 影响 |
|---|---|---|
| A | 保持现状（视为特性：鼓励多带武器） | 与「主武器/备用武器」的 UI 表达矛盾 |
| B | 主武器 100% + 备用武器 30% + 其余 0 | 削弱现有玩家战力，需公告 |
| C | 只取最高攻击的武器，其余装备只提供防御 | 大幅削弱，风险最高 |

**[推] 建议 B**，但**必须与 A 方向同批**——因为 A 方向在做「换武器有意义」，而 G6 恰恰在鼓励「全带上」。两件事不同批做，会互相抵消。
**阻塞级别** 🟡 —— 阻塞 A 方向的「武器选择」子项。
