# 白色装备多样性

测试起点 dff9e0971bf101ea70ec854f559ae5ca22f824c7。复用 R2 的隔离非开发验证 Player，并按固定发布清单核对全部构建文件。8 个进程各自启动合成角色和空存档。每组最多 18 个实际新 Run，或取得 2 件不同白色装备后结束。预先要求双刃、巨剑、镰刀各至少有 2 次真实产出，每件与源码及保存后的对象一致。

本轮 55 个实际新 Run 取得 16 件白色装备，其中双刃 5、巨剑 7、镰刀 4。8 个进程均退出 0。逐 Run 用固定身份复算广场箱矿石、晶屑、掉落资格、装备类型、实体 ID 与装备 ID。白色装备实际存档分页的 SHA256、品质、类型及空词缀均核对一致。所有装备与 Run 身份保持唯一。

固定公式使用两个不同的散列输入。广场箱由事件身份的 16 位前缀取模决定是否掉装备，装备类型由加入 /gear 的身份另取前缀决定。离线枚举 65,536 个前缀仅用于审计分支覆盖，55 个运行样本用于证明三类都可真实产出。本轮不从样本推断概率稳定性、实战稀有度或最终平衡。

R2 原始 White 用例在 18 局仅出现 1 件，仍为 FAIL。R2 重跑与本轮 8 组分别归档。
