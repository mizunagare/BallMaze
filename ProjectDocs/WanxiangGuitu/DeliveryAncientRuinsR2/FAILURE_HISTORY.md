# 失败与证据历史

- White 原始非开发 Player 实际退出 1。18 个正常新 Run 的矿石与晶屑断言通过，仅出现 1 个独立白色装备，低于预先设定的 2 个样本。WhiteRetry 以相同上限和门槛执行，9 个 Run 中出现 2 个不同装备 ID。两轮均归档。随机样本不足不作为产品概率故障结论。

- R1 的 BossPlayer1 与早期武器矩阵失败、旧引擎和验证历史均在固定基准原目录。R2 核对原始及发布副本哈希，保留其原始状态。
- 历史内存漂移、JobTempAlloc、MapMagic 版本标签、构建输入等同性分别保持开放。无经过校准的 GC 或 GPU 性能数据。
