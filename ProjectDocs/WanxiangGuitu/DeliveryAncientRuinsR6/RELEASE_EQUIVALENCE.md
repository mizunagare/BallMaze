# R6 发行等同性结论

R6 基于 f21f807fb39f38653d7d3a5d9a3e3371936fedbe。从 R5 保留的两份纯包做只读验证。两包各 193 个原始文件的 SHA256 与冻结清单一致。非开发配置、Bee 五项诊断关闭均通过，原始包无 R6 取证驱动。两份字节一致的纯包副本分别完成标题实画面与后台正常退出，退出码均为 0，合成文件未改。已核对 R5 的 42 张原始机位图、375 项历史证据和 2,413 项用户保护路径，哈希差异为零。[保护记录](Evidence/protection.json)

**本轮七机位没有观察到可归因于发行包的渲染回归。** 完整帧的跨包差异处于同包波动范围，结构化渲染状态逐机位一致。局部检查中只有营地静态候选区的 A/B MAE 上限略高于同包上限，未出现持续分离的像素。R6 保留所有严格像素不一致，R5 原始结果也保留。[跨包结果](CROSS_BUILD_RENDER_COMPARISON.md)

这个结论限定于当前两包、硬件、图形 API、固定场景与捕获时间。阻止 GraphicsSettings 写回后的因果影响仍 UNRESOLVED。逐 draw GPU Shader Variant、后处理独立像素对照、人工体验和玩法矩阵重跑均为 NOT_RUN。产品代码、资源、场景、Prefab 与项目配置冻结。没有重建原始发行包。[验收](ACCEPTANCE.md)
