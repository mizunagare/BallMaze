# 给试玩者的目标卡（Fresh）

本次请使用观察者分配的武器：____。请按自己的理解操作，可以自行查看游戏内信息。你可以说出正在想什么；不想继续时可以停止。这里没有按键答案，不要求挑战首领。

1. 从标题进入游戏，或在你认为适合时继续已有进度。
2. 看看角色的装备，准备本次武器，并尝试进入森林。
3. 在森林中移动、转向，说明你认为目前可以做什么、下一步想去哪里。
4. 用指定武器尝试普通攻击和技能，说说你如何判断攻击是否生效。
5. 遇到普通敌人时尝试躲避攻击，辨认自己命中和受击的反馈；不必主动挑战危险首领。
6. 获取一些材料或战利品，检查它们现在在哪里。
7. 根据当前生命、收获和风险决定继续还是离开；本次请最终完成一次合法撤离，并说明判断依据。
8. 回营核对带回物品，尝试制造一件你能制造的东西，调整后再次出征。材料不足或无法完成时请直接说明，不需要猜正确答案。
9. 修改一个你想改的操作键，检查提示和实际操作，按正常方式退出，再启动继续，看看修改与进度是否保留。

## Continue专项目标卡（单独队列）

1. 从标题继续这份已有进度，说明角色目前在哪里、拥有什么、接下来能做什么。
2. 核对装备与物资，使用一次基本操作，说明你如何理解显示与结果。
3. 修改一个操作键，验证提示和实际操作后正常关闭，再启动继续同一进度。

这是恢复专项，不称为首次进入营地试次；不能与Fresh的任务耗时直接比较。请勿阅读观察者指引后再进行“未讲解”试次。
