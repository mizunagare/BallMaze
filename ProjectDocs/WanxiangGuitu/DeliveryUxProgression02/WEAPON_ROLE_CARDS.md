# 七武器角色卡（WP02-01）

基线：`design/ux-progression-02` ← `verify/ux-progression-01-p1c` @ `4550348f`

标注约定：**[源]** 源码事实（文件:行）｜**[证]** 交付证据（Run ID / 证据文件）｜**[推]** 设计推论｜**[疑]** 待验证假设

所有数值来自 `Assets/CombatPrototype` 现有定义，没有任何一项由武器名称推断。
统一前提：英雄 `attackDamage=25`、`attackCooldown=.5`、`attackReach=1.8`（`ThirdPersonHero.cs:10`）。

## 通用事实（七把武器共享，先看这里再看单卡）

| 项 | 事实 | 出处 |
|---|---|---|
| 移动限制 | **七把武器全都没有移动锁**。前摇/释放/恢复期间可自由 WASD 位移；唯一限制是移动时关闭朝向辅助 | `AdventureCombat.cs:156`（`MoveDirection.sqrMagnitude>.01f` 直接 return）、`NewWeaponCombat.cs:31` |
| 取消规则 | 未释放段可被「暂停 / 开 UI / 换武器 / 翻滚 / 失焦 / 超时」取消；**已释放段不能取消**，必须走完 `endsAt` | `AdventureCombat.cs:63-68`、`NewWeaponCombat.cs:24,26`、`WeaponSkillExpansion.cs:58-60` |
| 暂停语义 | `GameplayPaused`（HUD/背包/存盘/升级选择）与 `Time.timeScale<=0` 时：动作不推进、弹体不飞行、区域不脉冲 | `ThirdPersonHero.cs:29`、`AdventureCombat.cs:136`、`WeaponSkillExpansion.cs:42` |
| 死亡 | 英雄死亡后弹体、冲击波、符阵、牵引立即销毁或停止 | `SkillPhysicalEffects.cs:6,21`、`GreatswordCombat.cs:15,20` |
| 卸载 | `OnDisable` 取消全部未释放段并清弹体 | `AdventureCombat.cs:96-97`、`WeaponSkillExpansion.cs:60` |
| 弹体 | 固定 `life=2.5s`；速度 法杖 16 / 弓 23（技能 14 / 23）→ 最远 40m / 57.5m | `AdventureCombat.cs:271,176` |
| 冷却门槛 | 普攻与技能共用 `attackAt / skillAt` 闸门，且要求 `actions.Count==0` | `AdventureCombat.cs:65,136,142` |

**[推]** 因为「无移动锁 + 已释放不可取消」同时成立，七把武器的核心差异其实只有三个轴：**有效距离 / 命中形状 / 循环周期**。没有任何一把靠「站桩换伤害」形成定位——这一点与角色卡文案里的「蓄力」「重斩」直觉相反。

## 1. 长剑（Sword）

- **[源] 普攻**：单段近身横扫。`reach=1.8m`（+专精 0.25/级），`dot=.25` → **半角 75.5°**，宽度无限（`AdventureCombat.cs:181`、`MeleeGeometry.InDirection`）。
- **[源] 时序**：`interval 0.5s`；前摇 `0.175s`；释放后到结束 `0.325s`（`BasicInterval` = `attackInterval×1`，释放比例 `basicRelease[0]=.35`）。
- **[源] 技能槽 0（内置）**：旋风横扫，半径 `4m`，`200%`，`7s`；紫起附加 1 道剑气（75%），金起 3 道，红起剑气 1.8m 爆（`AdventureCombat.cs:117,186`）。
- **[源] 扩展槽 1**：三拍连斩 `sword.triple`，3×65%，前摇 .22/段，间隔 .22，`2.5m`，半角 66°，`8s`（`WeaponSkillExpansion.cs:9`）。
- **[源] 扩展槽 2**：回旋剑阵 `sword.circle`，3×55%，`3.1m`，`dot=-1`（360°），间隔 .48，`11s`（同上行 10）。
- **[源] 词缀**：六条全生效。回响只放大槽 0 的 4m 半径与朝向辅助距离，**不放大两个扩展技能**。
- **[推] 定位**：容错基准线。宽角 + 短前摇，正面 3 个敌人一起吃到。
- **风险**：单体爆发是七把里最低（单次 25 伤害），一旦需要「从 4m 外开始打」就没有手段。
- **[证]** P1 的 13 条 Run 里长剑是起始武器，但**没有任何一条记录用长剑完成挑战目标**；P1C 三条闭环分别用的是 `boss:tide`（森林）、`c1:guardian`（遗迹）、`c24:boss:crystal-warden`（洞窟），驱动挑选的是「最孤立的强敌」，未记录武器选择。
- **[疑]** 长剑在 1v1 对精英（140HP/2.6m 攻击距离）时是否必须贴身换血 —— 未做对照实验。

## 2. 长枪（Spear）

- **[源] 普攻**：远距窄刺。`reach=3.1m`，`dot=.88` → **半角 28.4°**，横向 `|x|≤0.4m` 的板状判定（`AdventureCombat.cs:70,181`）。
- **[源] 时序**：`interval 0.65s`（`0.5×1.30`）；前摇 `0.22s`；恢复 `0.33s`。注意时长被 `ActionDuration` 夹在 `0.55s`，实际循环 0.65s（`AdventureCombat.cs:62,74`）。
- **[源] 倍率**：`SpearPower=1.25` → 单次 **31.25**，七把最高（`AdventureCombat.cs:72`）。
- **[源] 技能槽 0**：贯穿突刺，`7m`，`240%`，`7s`；紫起追加 `9m/80%`，红起追加枪芒弹（`AdventureCombat.cs:118,187`）。
- **[源] 扩展槽 1**：蓄势穿刺 `spear.charge`，`4.2m`，`120%`×蓄力系数（最高 1.85 → **222%**），蓄力 `0.85s`，`9s`，不穿墙（`WeaponSkillExpansion.cs:11`）。
- **[源] 扩展槽 2**：扫锋拒敌 `spear.sweep`，2×80%，左右各偏 32°，`3.2m`，±2m 横宽，`10s`（同上 12）。
- **[源] 词缀**：疾风把循环从 0.65s 压到 0.533s；聚能 +25% 只加**技能**伤害并 +1s 冷却；回响只放大槽 0 的 7m。
- **[推] 定位**：唯一能「在普通敌人 1.7m 攻击距离之外命中」的近战，靠距离而非闪避做防御。
- **风险**：窄角 + 0.65s 循环，对横向绕行的目标容错最差；蓄力期间（最长 0.85s）没有移动限制但也没有保护。
- **[证]** 无长剑/长枪对照 Run。

## 3. 法杖（Staff）

- **[源] 普攻**：单发直击弹，速度 16，爆炸半径 `0.9m`，`25` 伤害（`AdventureCombat.cs:180`）。
- **[源] 时序**：`interval 0.5s`；前摇 `0.225s`；飞行时间由距离决定（40m 上限 2.5s，`AdventureProjectile.life`）。
- **[源] 技能槽 0**：陨火爆裂，弹体 `220%`，爆半径 `4m`（紫起 5m）`×回响`，`7s`；紫起两枚侧球各 80%，红起侧球半径 3m（`AdventureCombat.cs:119,188`）。
- **[源] 扩展槽 1**：余烬符阵 `staff.field`，弹体 65% 接触后留下 `3m` 符阵，每 0.6s 一次 40%，共 3 次，`10s`（`WeaponSkillExpansion.cs:13`、`SkillPhysicalEffects.cs:21-23`）。
- **[源] 扩展槽 2**：回响连珠 `staff.echo`，3×55%，每发重新校验杖首与遮挡，`9s`（`WeaponSkillExpansion.cs:14`）。
- **[源] 词缀**：回响只放大槽 0 的爆半径；符阵半径 `3m` **不吃回响**（`Release` 直接传 `c.def.reach`）。
- **[推] 定位**：唯一稳定的面杀伤与「留场区域」，可以打「放完符阵后撤到安全距离」的节奏。
- **风险**：弹速最慢（16），必须靠第三人称相机瞄准；任何墙体遮挡即失效（`AdventureCombat.Sight`）。
- **[证]** 无 P1/P1C 法杖专项 Run。

## 4. 弓（Bow）

- **[源] 普攻**：单箭直击，速度 23，无爆炸，`25` 伤害（`AdventureCombat.cs:180`）。
- **[源] 时序**：`interval 0.5s`；前摇 `0.20s`；射程上限 57.5m。
- **[源] 技能槽 0**：扇形箭雨，箭数 `BowHalfCount(q)*2+1` → 白 5 / 绿紫 7 / 金红 9，相邻 12°，每支 120%，`7s`；**多箭可命中同一目标**（`AdventureCombat.cs:108,120,189`）。
- **[源] 扩展槽 1**：追点连射 `bow.burst`，3×55%，分时重瞄，`9s`（`WeaponSkillExpansion.cs:15`）。
- **[源] 扩展槽 2**：蓄势贯矢 `bow.pierce`，115%×蓄力系数（最高 1.85 → **213%**），**最多贯穿 3 个目标**，蓄力 1s，`11s`，实心场景立即阻挡（`SkillPhysicalEffects.cs:4-14`）。
- **[源] 词缀**：回响影响槽 0 的扇角与箭雨散射（`12*area`）；扩展技能不吃回响。
- **[推] 定位**：爆发上限最高（红弓箭雨 9×120% 若全部命中同一目标 = 1080%），且是唯一「远程贯穿」。
- **风险**：完全无自保；被贴到 1.8m 内只剩闪避。
- **[证]** 弓的蓄势贯矢有真实 Player 证据：`DeliveryCp06Integration02/Evidence/Player/bow-pierce-natural-7`（`PLAYER_RUN_COMPLETED`）断言 `bow-pierce-multi-target PASS pierceChain=2[enemy:9/enemy:8], bestLateral=0.40, contract=up to 3`，即**实测贯穿 2 个目标**，与源码上限 3 留有 1 个未验证档位。
- **[证]** 同批 8 次尝试里有 6 次 `DRIVER_FAILED`（`bow-pierce-natural-1..6` 中 1/2/3/5 失败、4/6 为 `OBSERVATION_COMPLETE` 非完整 Run），说明该操作路径本身脆弱 —— 这一限制必须保留，不能被「PASS」覆盖。
- **[疑]** 3 目标贯穿、蓄力满档（1.85 倍）与红弓爆炸箭雨三者未在同一个 Run 内验证。

## 5. 双刃（TwinBlades，新增 11）

- **[源] 普攻**：三段交替（右刃 42% → 左刃 42% → 双刃 85%），每段独立胶囊，`1.4m` + 半径 `0.38m`，贴身 `0.35m` 起（`NewWeaponCombat.cs:32,43-44`）。
- **[源] 时序**：`interval 0.30s`；前摇 `0.12s`；恢复 `0.16s`；**连段窗口 1.05s**（超过即回第一段）。
- **[源] 技能 A**：影袭连舞，6 段 ×40%（合计 240%），段间 0.13s，`1.4m`，`7s`。
- **[源] 技能 B**：双刃反击，基础 65%，**只有真实攻击被翻滚无敌窗拒绝后的 0.85s 内**才强化到 180%，`8s`（`NewWeaponCombat.cs:20`、`CombatHealth.AttackEvaded`）。
- **[源] 品质**：**没有任何品质专属效果**（`WeaponTraits.Exclusive` 对新增武器统一返回「独立武器机制」）。
- **[源] 词缀**：回响只作用于「技能段」（`phase>=10`），普攻不吃。
- **[推] 定位**：唯一有「防守转进攻」窗口的武器；DPS 靠循环次数而非单发。
- **风险**：单段 10.5 伤害（42%×25）是全武器最低，必须贴身且连续命中；一旦断连段就掉回起手。
- **[疑]** 反击窗口（0.85s）在真实网络/帧率下的达成率未测；P1C 驱动只统计 `dodgePressFrames=1`，未尝试反击构筑。

## 6. 巨剑（Greatsword，新增 12）

- **[源] 普攻**：单段蓄势扇形，`2.6m`，**半角 65°**，`105%`，`interval 1.05s`；前摇 `0.45s`，恢复 `0.5s`（固定收招）（`GreatswordCombat.cs:3,5,6`）。
- **[源] 技能 A**：崩山重斩，`170%`，`3.1m/50°`，前摇 `0.8s`，命中后**破防 0.75s**（`EnemyWeaponControl.Break`），Boss 免疫，`9s`。
- **[源] 技能 B**：裂地冲击，`95%`，沿地面前进 `8m`，半径 `0.3m`，遇实体障碍立即停止，`10s`（`GreatswordCombat.cs:19-21`）。
- **[源] 词缀**：回响只放大技能扇形（`phase>=10`），普攻不吃；聚能同时 +25% 伤害与 +1s 冷却（此处代价确实生效）。
- **[推] 定位**：单发最高（26.25）+ 唯一破防 + 唯一「地面前进」的直线清场。
- **风险**：1.05s 循环是七把最慢；0.45s 前摇期间移动无保护，靠「无移动锁」躲伤害会让这一击落空。
- **[证]** P1C 洞窟闭环记录到 `c24:boss:crystal-warden` 360→0 用了 10 次真实命中，但武器是长剑而非巨剑。

## 7. 镰刀（Scythe，新增 13）

- **[源] 普攻**：单段中距弧形，`3.0m`，**半角 85°**，`80%`，`interval 0.8s`；前摇 `0.3s`，恢复 `0.35s`（`ScytheCombat.cs:3,5,6`）。**明确不含背后目标**（`BasicDescription`）。
- **[源] 技能 A**：回旋收割，3×45%（合计 135%），`3.4m/125°`，段间 0.28s，`8s`。
- **[源] 技能 B**：灵魂牵引，`4.5m/50°`，把目标**限速拉到 1m 内**，持续 1s，对 Boss 免疫，`11s`（`NewWeaponCombat.cs:10`、`EnemyWeaponControl.cs:8`）。
- **[源] 词缀**：回响放大牵引距离（4.5→5.6m），扇形只放大技能段。
- **[推] 定位**：唯一「把远程敌人拉到近战距离」的控制；85° 弧是近战里最宽的有效面。
- **风险**：普攻 80%（20 伤害）低于长剑，靠面积换单体；牵引对 Boss 完全无效，因此对三个地区首领战没有额外价值。
- **[证]** 遗迹永久藏品 `c1.special.artifact`「回响遗镰」是**紫色镰刀**，洞窟首次击杀 `c24.special.crystal-warden-first`「晶脊初誓」也是镰刀型（`RuinsSpecialRewards.cs:28,42`）。也就是说**镰刀是唯一有确定性永久获取路径的新武器**，见 `REGION_MOTIVATION_MATRIX.csv`。

## 重叠判定（§3 明确要求）

| 被质疑的重叠 | 源码事实 | 结论 |
|---|---|---|
| 长剑 vs 双刃 | 长剑 1.8m / 75.5° / 0.5s / 单段 25；双刃 1.4m / 胶囊 / 0.30s / 三段 10.5-21.25 | **不重叠**：长剑是「一次判定大面」，双刃是「多次判定小面」。同样 10 秒，长剑 20 次 ×25 = 500；双刃 33 轮 ×(10.5+10.5+21.25) = 1394，但每次必须命中贴身胶囊。差距来自命中率而非定位 |
| 长枪 vs 巨剑 | 长枪 3.1m / 28.4° / 0.65s / 31.25；巨剑 2.6m / 65° / 1.05s / 26.25 | **部分重叠**：都能在普通敌人 1.7m 外命中。差异是「窄线高倍率快循环」对「宽扇低倍率慢循环 + 破防」 |
| 法杖 vs 弓 | 法杖 16 速 + 0.9m 爆 + 符阵留场；弓 23 速 + 0 爆 + 多箭/贯穿 | **不重叠**：法杖是「延迟面杀伤」，弓是「瞬时点杀伤」 |
| 长剑 vs 镰刀 | 镰刀 3.0m/85°/0.8s/20 伤害；长剑 1.8m/75.5°/0.5s/25 | **不重叠**：镰刀是「长剑的远距离低倍率版本 + 牵引」 |

**[推] 真正的重叠在「技能」而不在「武器」**：见 `SKILL_BUILD_MATRIX.csv` 的 `dominance` 列——每个旧武器的槽 0 内置技能在倍率与冷却上都优于它的两个扩展技能。
