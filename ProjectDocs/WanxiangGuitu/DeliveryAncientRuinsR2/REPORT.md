# CP06-C1-R2 独立验证报告

固定产品与证据基准 d19c461fb9f089fdffa9beab9e42bb1814b629aa。独立验证分支 verify/cp06-ancient-ruins-r2。R2 仅提交文档、外置测试驱动、审计工具和证据。分支产品树与基准逐项相同。

本轮实际取得 41 个通过案例，共 1,003 条 PASS，其中隔离 Editor 1 个案例、16 条，非开发 Player 40 个案例、987 条。白色装备首轮 18 局只抽到一个不同 ID，触发样本门槛 FAIL。相同门槛的重跑 9 局抽到两个不同 ID，首轮 181 条通过断言和 1 条失败断言完整保留，单独计数。原 R1 的 1,309 对源及发布文件与 579 个冻结构建文件通过 SHA256 核对。R2 独立读取 116 份 v9 封装并核验活动 Run 引用的地面页。所列测试均绑定独立进程命令、存档根和退出回执。

- 永久特殊装备满包、待领、首次领取、重复拒绝、实际拆解、跨进程和新 Run 重开均有证据。白、绿、紫常规掉落以及铁矿、晶屑、兽皮和核心复跑得到实际产物。
- 通过正式碰撞测到守护者两种新增招式命中与规避。七种武器在五区有受控真实攻击矩阵，另对实际存活 Boss 验证七种武器伤害、暂停取消和切换。全组合限制见武器矩阵。
- 跨进程覆盖正在探索、已开门与密室、死亡精英、受伤的一阶段和二阶段 Boss、待领与已领、撤离待提交与已提交。Boss 恢复重新进入前摇，旧攻击没有补发。
- 两套非开发验证构建使用固定发行保护与测试驱动。40 个核查产品类型与纯包 IL 一致。冻结纯发行包复制后在 R2 真实启动到标题并后台关闭，进程退出码为 0，隔离存档未改变。纯包和验证包分别归档。
- 用户文件、原分支和历史证据受保护。隔离工程与仓库有 16 项原始字节差异，具体文件见证据。字节等同性、内存漂移、JobTempAlloc 根因、MapMagic 版本标签差异分别维持 UNRESOLVED。GC/GPU 未校准，性能无通过结论。
