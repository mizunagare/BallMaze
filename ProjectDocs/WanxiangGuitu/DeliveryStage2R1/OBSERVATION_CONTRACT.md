# S2-R1 观测与统计合同

本轮只增加只读伤害转换事件、实验登记和发布证据检查。游戏伤害、生命、防御、冷却、无敌帧、AI、掉落、结算、来源账、v9 存档均不改规则。测试根位于工程外，所有库存均为合成营地数据。

## 事件与时钟

`CombatHealth.Observed` 的样本在实际 HP 赋值后立即捕获，携带 before/after、实际扣血、死亡转换、`Time.timeAsDouble` 和帧号，在原有反馈执行后分发。不把请求伤害或过量伤害计为实际扣血。观察者异常单独记录，不能阻止后续观察者；原有产品逻辑异常仍传播。没有订阅者时不创建列表。新事件不序列化、不决策伤害。

- 遭遇窗口：受控接近位置确定、所有敌人 AI 与碰撞启用之后开始，到目标首次实际 HP→0、玩家死亡或 180 活动秒限制结束。中途没有位置/属性覆盖。
- 攻击起点：真实 Strike/UseSkill 返回成功时登记，活动时间为该命令执行帧；近战同帧扣血可能先触发事件再返回成功，日志写入顺序不冒充亚帧时序。
- 首次扣血→死亡 TTK：同一 Run/区域/实体/遭遇内首次实际正扣血至首次正血→零的活动时钟差。首击击杀与多次同帧击杀均可合法为 0，不计算无限 DPS。
- 接敌前耗时：遭遇开始→首次扣血；独立于 TTK。Boss 原驱动先观察三次真实攻击，这段等待不混称 TTK。
- 精度：Unity 模拟活动时钟、帧精度，同帧事件有通知顺序；不是墙钟性能、亚帧测量或轮询采样精度。
- 治疗保留独立量，不抵消累计伤害；重复死亡/再次 DropLootOnce 不产生第二次测量。Reset/Restore/卸载将开放窗口标为 censored，不伪造死亡。已杀目标后不再增长命中数。
- 玩家承伤为开放窗口中所有来源的实际扣血总量。API 没有 attackerId，明确 **unattributed**，不猜测为目标专属伤害；可能有正常增援/其他敌人。药水仅真实 TryUsePotion 成功才计数。
- 观测 I/O 异常为粘性错误；驱动不得将其提升为完整证据。观测器不会吞掉产品异常或修复玩家状态。

## 跨进程

两个独立探针分别对普通近战敌、湖心潮灵执行：真实首次普攻扣血且目标存活→背包实际暂停→正常 SaveProgress→保存外置观测检查点→Editor 自行正常退出。新进程通过原保存系统恢复同一 Run，立即暂停并在下一 AI 帧前比较修订号及目标/玩家 HP、Run/区域/seed、随机流、装备 ID、地面掉落 ID、材料来源账、徽章/讨伐/结算身份。

暂停检查点证明间隔没有活动时间；新进程使用显式时钟段偏移，与保存时的活动累计对齐，不直接相减两个进程的 Time.time。first/death processSegment 分开记录。无法对齐则 censored+失败，不输出完整 TTK。保存版本不增加。最终使用真实攻击击杀、既有掉落和真实放弃/提交/ACK，重复操作不得增奖。恢复后仅对存活敌人要求碰撞启用；死亡尸体的控制器合法关闭。

## 配对与边界

`MATRIX_INPUTS.json` 在主试验前登记 18 条：长剑普通近战敌 3 seed×3 构筑；弓对同一湖 Boss 3 seed×3 构筑。每条件 n=1，不扩大为平衡结论。四武器×普通/湖 Boss 的额外 8 条是覆盖探针，不能混入主配对。预试、故障和重试另列。

允许一次受控接近摆放，明确不是从营地完整探索、原生输入或人工试玩。之后使用原有受控输入/战斗策略，正常 AI 全部运行；不锁血、不冻结敌人、不缩短 Boss 前摇。原可选后撤仅在完整 NavMesh 路径可用时发出，不能命令角色走入水域。无路停止该可选动作，不换 seed。主试验的结束规则为击杀/死亡/活动限时；剩余 Run 通过真实放弃提交，不把它写成成功撤离、收益或全冒险。

## 发布汇总

先登记 attempt，再记录出征事务。case、attempt、代码/驱动、配置哈希、Profile/Run/区域、实际阶段与进程必须一致。经济闭环还要求实际撤离、提交、ACK、不同后继森林及独立进程恢复。ACK 后活动 Run 可合法为空，以 Pending 的首局身份、Profile 和阶段断言关联；若非空却指向别局则拒绝。不能从自报 PASS 补造完成字段。

工具状态、业务结局、窗口完整性分别报告。已开始但缺指标仍进入 started/unknown；技术中断不当作死亡。已知结局撤离率分母仅 knownTerminal，同时公布 unknown/technicalInterrupted/notStarted。完整窗口、成功撤离、死亡/放弃、部分窗口分开；三构筑分别过滤。零样本不是 100%，空计划与未结束或变化中的输入不能终验通过。

R13 旧 19 条只读投影：检查既有输入、事务、检查点、日志阶段断言和实际进程回执，不捏造旧 attemptId/阶段哈希。旧原件不变；旧 schema 缺口明确保留。数量向量不折算虚构币值，制造后净材料/首局模拟秒不能称完整循环每分钟收益。

本轮不关闭阶段2/P0/发行验收。原生、独立人工、完整性能 NOT_RUN；D3D12 UNKNOWN、Editor 青色帧、Search 根因 UNRESOLVED。
