# B05 素材记录

本批没有下载或引入新的第三方模型、图标、音效或插件。继续复用此前已有 KayKit、Kenney 与 Game-icons.net 素材及其项目内署名/许可文件，没有因为“免费”推定新增用途许可。

本批未升级 Unity、URP、输入包或测试包；未导入额外角色控制、相机或渲染配置。后续 B06/B07 真正引入素材时，才逐文件记录来源、作者、许可、署名、用途与修改，不用本记录替代未来素材授权审查。
