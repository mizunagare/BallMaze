# WORLD-01：森林探索内容纵切与路线决策

仓库：`https://github.com/mizunagare/BallMaze`

## 1. 当前基线与目标

当前已知远端 `main`：`3b14dca0c246abdc71f44c02c765716d989fb6b4`。开工必须重新读取远端 `main` 完整 SHA；若已前进，审计新差异，不 reset、不覆盖用户工作区。

RUNLOOP-01/R1 已对结算、恢复和核心循环完成限定范围修复。下一阶段不再重复重写存档事务，也不继续盲目增加战斗参数，而是把已有森林探索做成更有决策价值的可玩纵切。

目标：玩家进入森林后，能识别路线、兴趣点、资源、普通遭遇、风险和撤离机会，并根据当前携带物资与风险选择继续或撤离。先审计现有功能，只有发现真实内容断点时才增加最小内容。不是扩展成大型开放世界，不引入新的经济或存档系统。

## 2. 严格边界

- 不升级 Unity、URP 或依赖，不新增 CI。
- 不改 v9 存档格式、随机流合同、现有经济成本、掉落概率和结算语义。
- 不改用户场景、ProjectSettings、未提交修改、真实存档。

- 本批不做全新地图，不做永久成长树，不做任务编辑器，不新增大型随机事件框架。

## 3. WORLD01-01：现有森林内容审计

审计并绘制实际森林玩法图，至少检查：
- `ForestRegionRuntime`、布局/兴趣点生成、资源节点、遭遇点、普通敌、双 Boss、出口与修复渡口。
- `AdventureFlow` 的出征目标、撤离条件、战利品来源、死亡/放弃规则。
- HUD/交互提示、地图或方向提示、兴趣点提示、敌人预警、目标说明。
- seed、layout revision、generationVersion、regionInstanceId 的生成与恢复合同。
- 现有内容是否能在固定 seed 下复现，存档后继续是否保持资源、敌人、事件、出口和地面战利品身份。
- 当前已有的每个兴趣点/资源/遭遇的玩法作用，不能只列对象名称。

输出 `WORLD_STATE_MAP.md` 与 `CONTENT_AUDIT.csv`，每项标注：已有且可复现、已有但反馈不清、规则或状态断点、当前没有此机制、需要后续设计批准的建议。禁止将“当前没有此机制”直接当作授权新增功能。

## 4. WORLD01-02：路线与兴趣点可读性

先检查玩家是否能在出发前和探索中理解当前目标、资源/兴趣点/出口/危险的大致方向、修复渡口的前置条件与成本、免费出口与修复出口的区别、双 Boss 是否为可选挑战，以及继续探索的潜在风险。

若现有 UI 信息不完整，只做最小提示修复：
- 交互提示必须与真实交互条件一致；无法交互时显示准确原因。
- 出口修复状态、距离、倒计时、取消原因与真实业务状态一致。
- 目标完成后清楚告知可继续探索或撤离，不强迫击杀所有敌人。
- 不能仅靠颜色表达重要状态。
- 不添加未经实现的地图标记、稀有度提示或风险数值。

如果现有系统没有地图界面，不要顺手创建完整地图。先给出轻量方向/目标反馈提案；超出最小修复的 UI 改造另列方案。

## 5. WORLD01-03：资源、遭遇与风险收益

通过固定 seed 和合成输入审计：
- 资源节点是否有稳定身份、合理可达性，拾取与地面战利品是否正确区分。
- 资源耗尽、敌人死亡、兴趣点使用、渡口修复是否在保存/恢复后保持一致。
- 同一兴趣点不能重复领取一次性奖励。
- Boss 可绕行；击败、徽记、地面掉落和撤离带回遵守现有规则。
- 携带物资、背包空间、药水、生命与出口距离是否影响现有决策。
- 死亡/放弃/撤离的物资后果与 UI 提示一致。
- 不为制造风险直接加高敌人血量、降低掉落或提高修复成本。

只有发现可复现缺陷才修复状态/反馈。若发现路线缺乏选择或兴趣点奖励缺乏吸引力等纯设计问题，先提交设计提案，不在本批擅自改经济和掉落。

## 6. WORLD01-04：最小可玩纵切

用一个或多个固定 seed 建立可重复的完整探索纵切：
1. 从营地开始森林探索 Run。
2. 玩家能看到当前目标和至少一个可选方向/兴趣点。
3. 完成一次真实资源交互并产生可追踪来源账。
4. 遭遇普通敌或现有遭遇；战斗状态、敌人死亡、掉落与拾取一致。
5. 经过兴趣点或出口，明确显示条件和风险。
6. 选择继续探索或撤离；条件不满足时拒绝原因正确。
7. 撤离后核对 Pending、Committed、仓库、随身保留物资与地面未拾取物。
8. 回营制造并再次出征。
9. 在关键阶段退出并新进程恢复，确认布局、资源、敌人、事件、出口、seed/revision 和地面物资身份一致。

如果现有内容无法自然形成上述纵切，记录缺口和最小提案，不硬编码业务结果或绕过真实入口。

## 7. WORLD01-05：固定矩阵

至少覆盖：
- 3 个固定 seed，每个 seed 至少 2 次独立运行；报告真实样本数。
- 入口、资源、兴趣点、普通敌、Boss、出口的生成与身份唯一性。
- 路线/出口可达性，资源与敌人不生成在不可达或无效区域。
- 资源拾取、兴趣点、Boss 奖励一次性。
- 战斗/采集后保存、退出、新进程恢复。
- 出口条件不足、修复成功、倒计时、取消、受击中断。
- 继续探索、成功撤离、死亡、放弃四种结局的来源账。
- 地面未拾取、背包物资、待领取、永久仓库的边界。
- 重复交互、重复结算、损坏存档、保存失败及恢复入口。
- 剑/枪范围回归与弓/法杖基本命中合同，不重新平衡武器。
- 正常 AI 三阶段和直接受影响的旧战斗规则回归。
- 非开发构建及完整错误/警告归档。

任何生成失败、不可达、身份重复或保存不一致必须作为明确 FAIL 或 UNRESOLVED 保留，不得通过过滤 seed 隐藏。
