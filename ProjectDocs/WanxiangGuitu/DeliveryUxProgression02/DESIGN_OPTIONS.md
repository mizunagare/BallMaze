## 0. 三个方向各自要解决的真实缺口

缺口编号引用 `EQUIPMENT_GAPS.md`（G1–G8）、`SKILL_BUILD_MATRIX.csv`（S）、`REGION_MOTIVATION_MATRIX.csv`（R）、`NEXT_RUN_MOTIVATION_AUDIT.md`（N）。

| 缺口 | 出处 | 一句话 |
|---|---|---|
| G1 | 装备 | 品质严格支配且**零代价**（尺寸由类型决定，不随品质） |
| G2 | 装备 | 双刃/巨剑/镰刀**没有品质专属效果**（旧武器紫起有） |
| G3 | 装备 | 「回响」对 4 把旧武器普攻 + 全部 8 个扩展技能 **0 作用**（半死词缀） |
| G4 | 装备 | 「聚能」+25% 技能伤害但它自己「+1s 冷却」的代价在 8 个扩展技能上**不收** |
| G5 | 装备 | 新武器**无制造入口**，紫以上只能靠 0.5%/4% 运气或洞窟首领 10% |
| G6 | 装备 | 盘内叠加：多把武器同时上板**攻击相加**，与「主武器」概念冲突 |
| G7 | 装备 | 分解单向亏损（红装分解返 5 铁矿，制造成本含 10 矿 + 4 晶 + 2 核） |
| G8 | 装备 | 护甲/长裤/护臂/战靴四件套**全是纯防御**，没有一件改变行为 |
| S1 | 技能 | 14 个扩展技能里多数 `vs_slot0 < 100%` 且冷却更长 → 「换了更差」 |
| S2 | 技能 | 蓄力类（`spear.charge`）与持续区域类（`staff.field`）缺乏独立的表达与提示 |
| R1 | 地区 | 遗迹收藏 5/5 集齐后只剩「每局 3 件装备 + 1 核心」，装备又无定向产出 |
| R2 | 地区 | 森林是唯一新武器随机来源，但它同时也是唯一 3% 小怪掉落 → 全部装备追求压在一个地区 |
| N1 | 结算 | 成功撤离仍显示「未竟之事」标题；三段建议**不读路线 Top3、不读目标历史**（只读材料缺口 + 当前目标卡 + 最近一次结果） |

**[推] 结论先行**：三个方向不是并列的三选一，而是**依赖顺序不同**。
A 与 B-1 不动存档、可在一次实现批内完成；C 必然新增持久字段，被 D-15 阻塞。

## 1. 方向 A · 横向构筑（武器 × 技能的横向差异）

**要解决**：S1、S2、G2、G3、G4。
**一句话**：让 7 把武器 × 14 个扩展槽**各自有存在理由**，而不是「槽 0 是最优解」。

| 项 | 内容 |
|---|---|
| 改动性质 | 数值 + 判定分支 + 文案；**零新系统、零新词缀、零新技能** |
| 具体候选 | ① 把 14 个扩展技能的 `power_total_pct` / `cooldown` 拉到「相对槽 0 的等效收益」区间；② 回响改判「技能与普攻都吃 reach，但普攻吃 area 的部分按 0.5 系数」；③ 聚能的 +1s 冷却对 8 个扩展技能同样生效；④ 给双刃/巨剑/镰刀补 1 条品质专属（沿用旧武器已有机制类型，不新增词缀） |
| 存档影响 | **无**。全部是运行时计算与文案，v9 字段不动 |
| 经济影响 | 无（不动材料、掉落、配方成本） |
| 可逆性 | 高。改的是常量与分支，回滚即恢复 |
| 验证成本 | 中。7 把武器各需 1 条真实 Player 战斗 Run（可比照 P1C 驱动，扩成 `p1c:<region>:<weapon>`），并需 14 个技能各 1 次真实按键释放 |
| 风险 | ① 改冷却/伤害直接触碰本批禁令，必须另开实现批并逐条授权；② 「等效收益」没有客观基准，容易变成拍脑袋 —— 需要用 SKILL_BUILD_MATRIX 里的 `power_total_pct / cooldown` 比值当唯一锚 |
| 不覆盖 | G1、G5、G6、G7、G8、R1、R2 |

**[推] 为什么它排第一**：它是唯一「不动存档、不动经济、不动随机流」且能直接改善「下一局换什么武器」的方向，而这正是 N1 想解决的问题。

## 2. 方向 B · 装备追求（品质代价 + 词缀对称 + 制造中段）

**要解决**：G1、G3、G4、G6、G7、G8（G5 已被 D-05 判为「维持掉落」，本方向不碰）。
**一句话**：让「更高品质」第一次有代价，让「词缀」第一次真正改变打法。

拆成两个可独立决策的子块：

### B-1 零存档风险块

| 项 | 内容 |
|---|---|
| 具体候选 | ① 聚能代价对扩展技能生效（同 A-③，两个方向共用）；② 回响改判（同 A-②）；③ 分解返还与制造成本挂钩（按品质返矿 1/2/3/5/8，仍低于成本，但不再「红装返 5 矿」）；④ 防具四件套各加 1 条**已有机制类型**的行为（如护臂影响翻滚冷却、战靴影响冲刺、护甲影响受击硬直、长裤影响采集）。②③④ 均不改 schema |
| 存档影响 | **无**（④ 若只加成运行时数值，同样无 schema 改动） |
| 经济影响 | ③ 改分解返还 = 改经济，**需要单独授权** |
| 验证成本 | 低-中。可用现有营地交互做确定性断言，无需 7 条战斗 Run |
| 风险 | ④ 会改变战斗手感，需与 A 一起验证，否则「护甲影响硬直」可能让 P1C 已通过的闭环失效 |

### B-2 需要决策、可能触碰存档的块

| 项 | 内容 |
|---|---|
| 具体候选 | ① 品质占更多格位（高品质 = 更大尺寸）→ **直接让已有存档里已放入盘内的装备越界**，`AdventureLoadout` 的放置校验会在读档时报错；② 盘内叠加改为「只取主武器攻击 + 备用武器 30%」→ 削弱现有玩家战力，且需迁移提示；③ 新武器加制造入口（D-05 已判「不做」，若要翻案必须重开 D-05） |
| 存档影响 | ① 必然 v10；② 无 schema 但破坏现值；③ 无 schema 但推翻既有决策 |
| 结论 | **[推] 本方向不建议在本阶段动 ①**。它解决的是「品质无代价」，但代价可以用**非存档**的方式实现（如高品质装备不可分解 / 修复成本随品质上升 / 占用法力或耐力条），没必要动 schema |

## 3. 方向 C · 地区精通（长期追求）

**要解决**：R1、R2、N1 的「下一局为什么还去这个地区」。
**一句话**：给每个地区一条**不可耗尽**的长期线，而不是「收藏集齐就结束」。

| 项 | 内容 |
|---|---|
| 具体候选 | ① 地区熟练度（每地区独立计数，按「撤离/首领/机关/满箱」累积，只加**展示**与**极小**的确定性收益）；② 地区专属材料（遗迹只产「符文」类、洞窟只产「晶」类）→ 直接影响制造，属经济改动；③ 地区终极目标（每地区 1 个跨局目标，如「遗迹 5 次守誓」），需要永久回执 |
| 存档影响 | **① 需新增字段；③ 需永久回执字段 → 全部 v10** |
| 授权状态 | 用户已明确「地区精通仍需单独授权」；D-07（精通数值）当前为「只展示」、D-14（目标历史）为 P3、D-15（存档修订）未拍板 |
| 验证成本 | 高。需要多局（≥3 局/地区）才能证明「长期线成立」，且必须证明不改变现有经济 |
| 风险 | ① 「极小收益」与「只展示」的边界很窄，一旦有数值就成了 D-06（持久等级）的翻版；② ② 直接改经济，违反本批禁令 |
| 结论 | **[推] 只能出设计，不能实施**。且必须等 D-15 拍板后一次性修订，不能零散加字段 |

## 4. 三方向对照

| 维度 | A 横向构筑 | B-1 装备零风险块 | B-2 装备存档块 | C 地区精通 |
|---|---|---|---|---|
| 覆盖缺口 | S1 S2 G2 G3 G4 | G3 G4 G7 G8 | G1 G6（G5 需翻案 D-05） | R1 R2 N1 |
| 存档改动 | 无 | 无 | 有（v10） | 有（v10） |
| 经济改动 | 无 | ③ 有（需授权） | 无 | ② 有 |
| 新增系统 | 0 | 0 | 0 | 1–2 |
| 违反本批禁令 | 改数值/冷却 → 需另批授权 | ④ 改护甲行为 → 需另批授权 | 改格位 = 改装备规则 | 新增持久系统 |
| 实现批次数 | 1 | 1 | ≥2（含迁移） | ≥2（含 schema） |
| 验证成本 | 7 条战斗 Run + 14 次技能释放 | 营地确定性断言 | 存档迁移 + 回归 | ≥9 条 Run（3 局/地区） |
| 可逆性 | 高 | 高 | 低（已存档数据） | 低 |
| **[推] 建议顺序** | **1** | **2** | 4（v10 后） | 3（与 B-2 同一 schema 批） |

## 5. 推荐组合（供审核）

**[推] A + B-1 合并为一次实现批（UX-PROGRESSION-03）**，理由：

1. 两者共享两处改动（回响改判、聚能代价），合并后只需一次验证；
2. 都不动 schema，不触发 D-15；
3. 合起来能同时回答「换武器有意义吗」和「换装备有意义吗」这两个下一局动机问题（N1）；
4. C 与 B-2 归入 UX-PROGRESSION-04，前置条件写死为「D-15 拍板 + v10 授权」。

**不推荐**先做 C：它是唯一需要新增系统的方向，而当前证据里**没有任何一条**能证明「玩家已经把现有内容耗尽」。R1 的「收藏集齐后动力下降」是设计推论，不是实测；P1C 每地区只有 1 条 Run，重复性未验证（已在 P1C 报告列为未做项）。在没有实测的前提下加长期线，等于用新增系统掩盖证据缺口。
