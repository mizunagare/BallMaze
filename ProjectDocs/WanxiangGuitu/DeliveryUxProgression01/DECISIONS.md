# UX-PROGRESSION-01 · 待决设计决策（D-01 ～ D-15）

> 每条决策给出：**问题 / 选项 / 建议 / 影响面 / 是否触碰禁区 / 谁需要拍板**。
> 建议栏是设计方判断，不是既成事实；未拍板前，实现批次**不得**默认采用建议值。
> 风险等级：🟢 只读或纯展示；🟡 需新增存档字段；🔴 触碰经济/数值/随机流（本周期禁止）。

---

## D-01 · 目标达成是否改变收益

| 项 | 内容 |
|---|---|
| 问题 | 目标完成后，玩家拿到什么？ |
| 选项 | **A** 纯记录（无任何收益，只有角标与回执）<br>**B** 走既有通道：解锁一条既有配方，或发一个既有 `specialRewardId`<br>**C** 直接发材料/装备 |
| 建议 | **A → B（分批）**。P1 先做 A；B 需单独授权，且只能复用 `unlockedRecipes` / `specialRewards`，不得新增货币 |
| 依据 | 目标是"意义层"，收益应由既有经济承担；C 会改变材料产出（I1） |
| 影响面 | A 🟢；B 🟡（新增回执字段）；C 🔴 |
| 需拍板 | 产品负责人 |

## D-02 · 目标是否允许局内切换

| 项 | 内容 |
|---|---|
| 问题 | 玩家进图后发现目标不合适，能否改？ |
| 选项 | **A** 不允许，只能营地选<br>**B** 允许一次，切换即重置进度<br>**C** 随时切换，进度各自独立 |
| 建议 | **A**。目标的意义来自"承诺"；可随时改会让目标退化为提示条 |
| 影响面 | A 🟢（零成本）；B/C 需新增进度状态 🟡 |
| 需拍板 | 设计 |

## D-03 · 技能槽配置存在哪里

| 项 | 内容 |
|---|---|
| 问题 | 玩家选的技能槽，下次进游戏还在吗？ |
| 选项 | **A** 新增存档字段（每武器 1 字节，7 条）<br>**B** 写入本地 `GamePreferences`（跨进程、不跨机器）<br>**C** 不持久化（现状） |

| 依据 | `CombatSaveData.cs:5-22` 无该字段；`WeaponSkillPanel.cs:5` 选择仅内存 |
| 影响面 | A 🟡（schema + 迁移）；B 🟢；C 🟢 |
| 需拍板 | 技术负责人（涉及存档修订窗口） |
