## 3. 五个重点的 R1 定稿

### 3.1 14 项扩展技能的收益与代价

恒等式 `η = 1 + (B−1)×W/C` 保留，**[推] B<1 时降冷却只会更糟**。

| 口径 | 数值 | 说明 |
|---|---|---|
| 扩展技能总数 | **14** | R1 保留 |
| T1 / T2 输出技能 | **1 + 11 = 12** | 唯一使用 B/η 做目标判定的范围 |
| T3 | **2**（条件反击 1 + 纯控制 1） | B/η 仅附录，`N/A (T3)` |
| **`8/14 B<1`** | 全 14 项 | **含 2 个 T3，不代表 8 个输出技能弱于普攻** |
| **`6/12 B<1`** | T1/T2 | 这才是输出技能的现状计数 |
| 提案后 | **12/12 `MODEL_PASS`** | `B' 1.025–1.652`、`η' 1.003–1.067`，**仅离线模型** |

**不追平槽 0 倍率**：槽 0 `W/C≈0.071`、扩展 `0.05–0.19`；槽 0 吃品质、扩展技能不吃
（白→红 D 增长 1.73–2.13 倍，红弓 η=1.700）。

### 3.2 回响词缀适用规则

**[源]** 10 个技能生效（4 旧槽 0 + 6 新武器技能）／15 个不生效（7 套普攻 + 8 个旧扩展技能）。
**R-1**（规则显式化 + UI 枚举，0 判定代码）是默认包唯一项；**R-2/R-3 属 L2，需单独授权**。

### 3.3 聚能对称性

收益侧 18 个技能 ×1.25 对称；代价侧 10 收 / 8 个旧扩展技能白拿。
**E-A** 补 `WeaponSkillExpansion.cs:39` 与 `AdventureCombat.cs:104` 两处；与 §2 提案合并后
**8/8 `MODEL_PASS`**（`FOCUS_SYMMETRY_IMPACT.csv`）。E-B 不进默认包。

### 3.4 七武器构筑与验证矩阵

**[推] 两个 R 梯队**：长剑/法杖/弓 `2.000 ×P/s`；长枪 1.923、双刃 1.878；
**巨剑/镰刀 1.000**（长剑的一半，靠扇形换覆盖）。
`WEAPON_BUILD_VERIFICATION_MATRIX.csv` 每套构筑写明真实装备获取路径、独占机制、有效带与逐 Run 断言；
T3 行改为专属指标，不产出 η。训练场与三地区远征分开计。

### 3.5 品质专属：全部 DESIGN_ONLY

9 条提案（每武器紫/金/红）**全部移出默认实施包**，只在 CSV/MD 登记，`不得写入产品代码`。
2 条 L2（双刃紫、巨剑红）继续需单独授权；巨剑金/镰刀金与回响叠乘到 `0.525m/12.5m` 波与
`7.0m` 牵引，**必须先有明确上限决策**。
