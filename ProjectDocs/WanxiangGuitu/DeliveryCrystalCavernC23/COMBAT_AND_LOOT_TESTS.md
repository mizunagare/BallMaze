# 战斗与物资验证口径

## 正常 AI 与受控命中分开

`EditorInnerVerified`、`PlayerInnerVerified` 让南岸巡守保持实际 AI：接近、攻击、玩家正常 Strike、实际敌人生命下降，玩家沿南岸侧边退出并抵达对岸。`ai.tsv` 和 `enemy-health.tsv` 记录敌人身份、状态、位置、生命变化，`health.tsv` 记录玩家实际承伤。没有修改敌人 HP 或禁用 AI。

`EditorLiveVerified`、`PlayerLiveVerified` 是专项受控几何夹具：固定目标位置/生命并单独禁用其 AI，以七种武器各自普攻及默认技能执行实际产品攻击、命中几何、弹体、Damage 和生命差额。每种攻击另有真实晶柱遮挡负例。固定目标不是正常 AI，不宣称这批夹具证明完整人工战斗体验。原始 trace/health/断言见相应用例目录。

两条路线的 Routes 用例在不打开桥的条件下实际双向移动；额外 Audited 轨迹保留每段 NavMesh corners 与真实 CharacterController 岸壁阻挡。导航完整不代替实际移动，二者分开断言。

## 普通资源与恢复

- Store：湖岸采矿、真实拾取、机关开启、宝箱生成后保留地面奖励，写入合成档。
- Resume：新进程恢复同一 Run；桥门与事件一致；库存矿物数量一致；地面每项 ID、种类、数量及完整装备 JSON 一致；返回入口执行免费撤离与提交。
- Warehouse：再一新进程读取营地档，核对材料和已提交 Run 回执；重复确认/提交不增加物资。
- Repeat：从已入仓营地再次出征，确认新 Run、节点未采集、宝箱未开，真实获得新一批正常奖励；来源身份与前 Run 不同。
- Closed/ClosedResume：关闭桥门保存及新进程恢复，门仍阻挡而两条岸路可用。
- ContinuousAudited/ContinuousWarehouse：不中途恢复的完整探索—结算—新进程入仓链，单列正常连续样本。

保留地面未拾取与已入库存的区别；测试没有把宝箱地面装备计入永久仓库。追加普通供给的来源和规则见 [SAVE_COMPATIBILITY.md](SAVE_COMPATIBILITY.md)。本轮不声称覆盖晶核精英新死亡批次的完整装备恢复，因为精英规则没有变化且这不是新增精英验证。

## 有限异常与旧接口

NavFailure 用例仅在隔离夹具中暂时把一个导航目的点置于地图外，使真实重建校验失败；检查 Used 不变、门关闭、旧导航可返回，恢复夹具后合法重试开启。该故障夹具不保存地图，不冒充玩家过程。

Hazard 用例保持旧恢复窗/预警窗无伤与真实翻滚避开脉冲。Death 用例明确使用测试开始时 1HP 的受控条件，经真实危险区伤害触发死亡、结算及卸载；不是连续冒险样本。历史暂停/死亡规则和新地图的导航开关互不替代。

旧 C2.1/C2.2 和森林/遗迹恢复分别读取已有合成档并核对实际版本及状态。C2.2 原资源名为 Cavern，首轮错误测试断言被保留；修正后的检查使用精确版本映射、克隆名、地面/阻挡数量、位置、尺寸与材质引用。
